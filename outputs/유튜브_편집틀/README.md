# 「윤단장의 보험시선」 편집 틀 한 벌

매 영상 같은 틀을 쓰면 시청자가 **「그 채널」 로 기억**합니다. 색은 **남색 + 금색** 하나, 글꼴은 **Pretendard** 하나.
틀은 `kit.html` 한 장에서 나오고 `node kit-render.js` 로 다시 굽습니다(이름·직함·슬로건은 맨 위 `PROFILE`).

## 편집 규칙 한 장

**롱폼(8~15분)**
1. **0~10초 후킹** — 얼굴로 바로 질문 하나(「암 진단받으면, 첫해에 실제로 얼마 나가는지 아세요?」) + 가장 센 화면 한 컷
2. **인트로 4초**
3. **이름표** — 처음 얼굴이 길게 나올 때 6초
4. **챕터 3~5개** — 챕터 카드 2.6초로 넘기고, 챕터마다 앱 화면을 꼭 하나 이상 (말만 이어지면 이탈합니다)
5. **정리 30초** — 「오늘 세 가지」
6. **끝 화면 20초**

**쇼츠·릴스(30~60초)** — 롱폼에서 잘라냅니다
1. **첫 3초에 가장 센 숫자나 화면** (인트로를 앞에 넣지 않습니다)
2. 자막은 크게, 화면 가운데보다 조금 아래 · 한 줄 10~14자
3. 끝 3초 쇼츠 끝카드

**자막(캡컷)** — 「자동 캡션」 → 출처 「보이스오버」 · 한국어 → 흰 글씨 + 검은 테두리 · 굵게 · 금색은 숫자에만

**썸네일** — 큰 말 6~10자(숫자 하나) · 작은 말 한 줄 · 얼굴은 오른쪽 · 시리즈 띠 색은 그대로.
얼굴 사진을 주시면 `PROFILE.photo` 에 넣어 회차마다 제가 뽑아 드립니다.

## 꼭 지킬 것 (보험 유튜브)

- **특정 상품·보험사를 추천하거나 비교하지 않습니다.** 화면에 상품명·회사명이 보이면 가립니다.
- **「무조건 이득」 「손해 없음」 같은 단정, 수익 약속을 하지 않습니다.** 보험료·보장은 「심사 결과에 따릅니다」.
- **세금은 「요건 충족 시」 와 요건만** — 한도·나이 같은 숫자는 말하지 않고 세무 전문가에게 넘깁니다.
- **고객 사례는 동의 + 이름·얼굴 가림, 아니면 견본(홍길동).**
- **통계는 출처를 화면에** — 앱 보고서의 「출처」 장에 있는 것만.
- 올리기 전에 **회사 준법감시 심의**. 상품이 나오는 내용이면 협회 심의 대상인지 회사에 확인합니다. 대본은 앱의 「외부글 심의필터」 로 먼저 걸러 봅니다.

## 다시 굽기

```bash
export NODE_PATH=/opt/node22/lib/node_modules
node kit-render.js                       # 한 벌 전부 (2분쯤)
node kit-render.js chapter03 end169      # 일부만
node kit-render.js "thumb|노후 연금|65세부터|매달 얼마 받나"   # 썸네일 한 장 (kit-render.js 의 JOBS 에 줄을 더하면 이름이 붙습니다)
```

영상(mp4)은 저장소에 넣지 않습니다 — netlify 가 저장소 루트를 라이브에 올리기 때문입니다.
