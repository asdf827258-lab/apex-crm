두 가지 판이 있습니다.

| 판 | 길이 | 파일 | 소스 |
|---|---|---|---|
| **이야기형 (막막이)** | 43.5초 | `out/스토리릴스_*.mp4` (A·B·C·**D 나를 알리기**) | `story.html` |

## 이야기형 — 사무실에서, 흔한 방식 vs 실제 앱 화면

신입 설계사 「막막이」(직접 그린 SVG)가 **설계사 사무실**(낮 사무실 · 새벽 2시 사무실 · 상담실, 직접 그린 SVG)에서
영업의 다섯 고비를 넘습니다. 배경은 장면마다 바뀌고 카메라가 늘 천천히 움직입니다.

고비마다 **BEFORE 2초 → AFTER 3초**:

- **BEFORE · 흔한 방식** — 막막이가 울고, 줄 그어진 지인 명단·거절 통화 목록·약관 더미·`#REF!` 엑셀·포스트잇이 떨어집니다.
  (특정 회사를 깎아내리지 않습니다 — 「흔한 방식」 일 뿐입니다.)
- **AFTER · 실제 앱 화면** — 우리 앱을 **실제로 찍은 화면**이 폰에 담겨 올라오고, 노란 칸으로 핵심을 짚으며 확대해 들어갑니다.

| 고비 | 막막이의 고민 | BEFORE | AFTER(실제 화면 `shots/`) | 핵심 한 줄 |
|---|---|---|---|---|
| 1 찾기 | 만날 사람이 없어… | 줄 그어진 지인 명단 | `home` — 오늘 챙길 것 · 지역 동선 | 누굴·어디서 만날지 앱이 먼저 정리한다 |
| 2 연락 | 전화 걸기가 무서워… | 부재중·거절 통화 목록 | `ta_script` — 5단계 연속 대본 · 고객 속마음 | 첫 마디부터 거절까지 대본이 있다 |
| 3 상담 | 질문 하나에 머리가 하얘져 | 약관 200쪽 더미 | `fp_talk` — 재무설계 실전화법서 | 상황을 고르면 그 장이 바로 열린다 |
| 4 제안 | 분석·제안서에 밤샌다 | 새벽 2시 `#REF!` 엑셀 | `bojang` — AI 보장분석 | PDF 하나 올리면 상담 리포트로 |
| 5 관리 | 계약 뒤가 더 막막해 | 「놓침」 포스트잇 | `assistant` — 오늘의 AI 비서 | 챙길 일은 앱이 먼저 알려 준다 |

끝은 **막막이 → 척척이** → 「수입은 약속 안 한다. 무기는 약속한다.」 → **소개 카드(나)** → 댓글 「무기」.

### 실제 앱 화면을 다시 찍기 — `tools/snap-app.js`

```bash
export NODE_PATH=/opt/node22/lib/node_modules
node tools/snap-app.js shots              # 다섯 장 다시 (앱이 바뀌면)
node tools/snap-app.js shots claims       # 다른 화면도 찍어 볼 수 있다 (탭 id)
```

`scripts/smoke.js` 와 같은 방식으로 로그인·서버를 가짜로 세우고 폰 폭(430px)으로 엽니다. 서버를 부르지 않고,
브라우저에 고객 자료가 없으니 **실제 고객 이름은 찍히지 않습니다**(견본 이름 홍길동). 떠 있는 단추·첫 안내 창은 걷어 냅니다.

**일부러 안 쓴 화면** — SNS 는 누구나 봅니다.
- **상품전략기**: 맨 위에 「판매인 교육용 · 고객 제시 불가」 가 적혀 있고 실제 보험사·상품 이름이 나옵니다.
- **거절 근육 훈련**: 다른 강사 이름과 강의 링크가 보입니다. → 같은 「연락」 고비는 TA 스크립트로.
- **DB 통합 CRM**: 따로 로그인해야 열리는 화면이라 빈 로그인 창만 찍힙니다.

화면을 바꾸면 `story.html` 의 `PAINS` 에서 `shot` 과 노란 칸 `rings`(폭 430 기준 좌표 `[x, y, 폭, 높이]`)를 고칩니다.

### 나를 알리기 — `PROFILE`

`story.html` 맨 위의 `PROFILE` 한 곳만 고치면 소개 카드 · 끝 인사 · D 후킹이 함께 바뀝니다.

```js
var PROFILE = {
  name:'윤시현', title:'에이플러스에셋 온탑본부 사업단장', career:'보험·재무설계 10년',
  slogan:'보험을 파는 설계사가 아닌,<br>삶을 설계하는 설계사',
  channels:['▶ 유튜브 「삶을 설계하다」','📷 인스타그램'],
  handle:'',   // '@아이디' 를 적으면 끝 인사에 붙는다
  photo:''     // 'me.jpg' — 이 폴더에 정사각 사진을 두면 이름 첫 글자 대신 사진
};
```

값은 앱 안의 콘텐츠 페르소나(`app/index.html` 의 `DEFAULT_PERSONA`)에 적혀 있던 것을 옮겼습니다. **다르면 고쳐 주십시오.**

**D_나를알리기** 는 슬로건으로 엽니다 — 「보험을 파는 설계사 말고, **삶을** 설계하는 설계사.」
리쿠르팅 광고보다 **내 계정 팔로워를 늘리는 게시물**로 쓰기 좋습니다.

D 캡션 (복사용):


## 일부러 안 넣은 것

- **수입 숫자·「월 ○○○ 보장」 같은 말.** 모집 광고에서 소득을 장담하면 거짓·과장 구인광고가
  되고, 지원자가 와서 처음 듣는 말이 「그건 아니고요」가 됩니다. 대신 그 자리를
  **「수입은 약속 안 한다. 무기는 약속한다.」** 로 뒤집었습니다. 영상에서 제일 센 한 방이 이 줄입니다.
- **지어낸 후기·가짜 사례.** 폰 화면은 「예시 화면」 표시를 달았고, 견본 이름은 홍길동, 나머지는 김○○처럼
  가렸습니다. 금액은 하나도 적지 않았습니다.
- **남의 음원.** 비트는 `beat.py` 가 직접 합성합니다. 저작권 문제가 없어 광고로 돌려도 됩니다.
  인스타 앱에서 유행 음원을 덧입히고 싶으면 원래 소리를 줄이고 올리시면 됩니다.

맨 끝 작은 글씨 두 줄(자격시험·등록 절차가 필요하다, 수입은 사람마다 다르다)은 빼지 마십시오.
**올리기 전에 소속 회사의 광고 심의(준법감시)를 한 번 거치십시오.**

## 타깃팅 요령

- **사람은 영상이 고릅니다.** 채용 광고는 플랫폼에 따라 나이·성별 타깃이 막히기도 합니다.
  그래서 첫 3초를 셋으로 나눴습니다 — 「월급」 에 멈추는 사람, 「하원 시간」 에 멈추는 사람,
  「감으로 영업」 에 멈추는 사람은 서로 다릅니다.
- 셋을 같은 예산으로 2~3일 돌리고 **3초 시청률·댓글 「무기」 수**로 이긴 쪽을 남기십시오.
  지는 버전은 후킹 글만 바꿔 다시 굽습니다(아래).
- 댓글 「무기」 → DM 자동응답(인스타 자동 DM 도구)을 걸어 두면 댓글이 곧 명단이 됩니다.
  DM 에는 다음 단계(설명 자리·면담 일정)를 적되, 여기서도 소득 숫자는 약속하지 마십시오.

## 다시 굽기 · 고치기

```bash
export NODE_PATH=/opt/node22/lib/node_modules
node render.js story    # 이야기형 넷 다 (한 편에 2~3분)
node render.js story D  # 나를 알리기만
node render.js          # 글자형 셋 다 (한 편에 1분쯤)
```

- 고비·핵심 한 줄·메뉴 꼬리표는 `story.html` 의 `PAINS` 에, 막막이 움직임은 `CH` 시간표에 있습니다.
- 후킹 글은 `reel.html`·`story.html` 의 `VARIANTS` 에 있습니다. D 를 하나 더 넣고 `render.js` 의 `NAMES` 에
  이름을 붙이면 네 번째 버전이 나옵니다.
- 끝의 「무기」 낱말·브랜드 이름·작은 글씨도 `reel.html` 에서 바로 고칩니다.
- 브라우저에서 `reel.html#A` 를 열고 콘솔에 `render(18.2)` 를 치면 그 순간 화면을 볼 수 있습니다.
- 글꼴은 Pretendard(공개 글꼴, jsdelivr) 를 받아 씁니다.
