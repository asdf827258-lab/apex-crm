# 설계사 리쿠르팅 릴스 — 세로 1080×1920 · 30fps

두 가지 판이 있습니다.

| 판 | 길이 | 파일 | 소스 |
|---|---|---|---|
| **끝까지 (이야기형 · 지금 판)** | 60.5초 | `out/끝까지릴스_*.mp4` (A·B·C·**D 나를 알리기**) | `story.html` |

영상(mp4)은 저장소에 넣지 않습니다 — netlify 가 저장소 루트를 통째로 게시해 라이브 사이트에 올라가기 때문입니다.
`node render.js story` 로 다시 굽습니다.

## 끝까지 — 고객을 끝까지, 설계사를 끝까지 돕습니다

리쿠르팅 영상입니다. 「무기」 대신 **고객을 걱정하는 마음**과 **끝까지 돕는다**로 갑니다.
신입 「막막이」(직접 그린 SVG)가 사무실(낮 · 새벽 · 상담실, 직접 그린 SVG)에서 겪습니다.

| 초 | 장면 |
|---|---|
| 0–3 | 후킹 (A 직장인 · B 육아 · C 경력 설계사 「4년 분급, 팔고 끝이면 못 버팁니다」 · D 내 슬로건) |
| 3–8 | 밤 11시 42분, 고객 메시지 「설계사님… 저 수술 날짜 잡혔어요.」 → **그 순간, 내 설계가 그 가족을 지킵니다.** |
| 8–11 | BEFORE · 흔한 방식 — 「그런데 고객 보험, 아직 이렇게 보세요?」 (`#REF!` 엑셀 · 새벽 2시) |
| 11–18.6 | **AFTER · 실제 앱** — 「보장 전·후」 고객 앞 발표 네 장 (운용보고서 표지 · 모든 담보 21→34 · 가족에게 남는 것 · 맡겨 주시면) |
| 18.6–24.9 | **치료 과정 · 사진** — 실제 앱 「치료 한 바퀴」 보고서 네 장: 암 한 바퀴(사진 다섯) → 항암약물(지금 0원 → 4,000만원) → 한 바퀴 합계(2,021만원 → 1억 3,021만원) → 뇌혈관 119 구급차(2,000만원 → 4,000만원) |
| 24.9–30.5 | **연금 계산** — 실제 앱 재무설계 계산기 세 장: 한 장 막대(목표 400 · 지금 80 · 함께라면 170) → STEP 3(월 50만원 × 10년 → 65세부터 평생 매달 79만원 · 최저보증, **상품명 가림**) → STEP 4(매달 +90만원 · 평생 +3억 7,595만원 · 변액 가정 기준) |
| 30.5–33.5 | **이것만 있으면, 나도 할 수 있겠다.** (막막이 → 척척이) |
| 33.5–36.5 | **4년 분급 시대. 이제는 얼마나 팔았나보다 얼마나 지켰나.** |
| 36.5–43.5 | 실제 「4년 유지관리」 48개월 차례를 1개월 → 48개월 굴려 내려갑니다 · 「48개월, 한 달도 비지 않게」 |
| 43.5–47.5 | 고객 메시지 「설계사님, 끝까지 챙겨 주셔서 정말 고마워요 🙏」 → **끝까지 곁에 있는 설계사.** |
| 47.5–51.5 | **우리는 고객을 끝까지, 설계사를 끝까지 돕습니다.** |
| 51.5–55.5 | 함께 걸어갈 리더 — 소개 카드 (`PROFILE`) |
| 55.5–60.5 | **함께할 설계사를 찾습니다.** 처음이어도 괜찮습니다 · 교육 · 상담 도구 · 4년 관리 · 📩 DM 으로 면담 신청 |

**발표 다섯 장** (`app/ba.html` 「고객에게 보여주기」 를 견본 고객으로 찍은 것 · `shots/ba_*.jpg`)

1. 표지 — 고객 이름이 박힌 「보험 자산 운용보고서」
2. 한눈에 — 지금 → 조정 후, 매달 얼마가 달라지는지
3. 한눈에 모든 담보 — 지금 21개 → 조정 후 34개
4. 가족에게 남는 것 — 「막내가 독립하는 14년을 덮습니다」
5. 맡겨 주시면 — 「보험은 가입이 끝이 아니라 **받으실 때까지가 제 일입니다**」

**치료 한 바퀴 네 장** (`app/ba-report.html` · `tools/snap-report.js` · `shots/tx_rep*.jpg`) — 보고서는 장마다 **위키미디어 공용(Commons) 사진**을 쓰고
「사진 · 지은이 · CC 라이선스 · 위키미디어 공용」 을 장 안에 적어 둡니다. 출처 줄이 잘리지 않게 **장 전체**를 찍었습니다.
견본 자료에 실제 보험사 이름(「조정 후 ○○화재」 등)이 들어 있어 찍을 때 「○○」 로 가렸습니다.

**연금 세 장** (`app/finance.html` 견본 넣기 `finSample()` → 연금 시뮬레이션, 네 단계를 모두 펴서 `shots/fin_*.jpg`) —
상품 고르는 칸은 「○○연금보험 (상품명 가림)」, 안내 글 속 회사·상품 이름도 「○○」 로 바꿔 찍었습니다.
화면 아래에 「최저보증·가정 수익률 기준의 예시이며 확정 금액이 아닙니다」 를 붙였습니다.

소리는 감동 구간(아플 때 · 고마움 · 끝까지)에서 북을 줄이고 화음과 피아노 같은 오르내림이 앞으로 나옵니다(`beat.py` · 직접 합성).

### 지킨 것

- **고객 메시지 두 통은 연출 장면**입니다. 말풍선과 끝 작은 글씨에 「연출 장면」 이라고 적었습니다 — 지어낸 후기를 진짜처럼 보이게 하지 않습니다.
- 발표 장은 앱 스스로의 견본(`doSample`)인데, 거기 **실제 보험사·상품 이름**(그리고 일부를 「해지」 하는 판단)이 들어 있습니다.
  SNS 에 나가므로 `tools/snap-ba.js` 가 **찍을 때만** 보험사 → A사·B사…, 상품 → ○○보험, 고객 → 홍길동으로 바꿉니다. 앱은 안 건드립니다.
  태블릿 위에 「견본 고객 · 예시 숫자」 를 붙였습니다.
- 4년 분급은 앱의 「4년 유지관리」 와 같은 말만 씁니다 — **환수 기준 같은 숫자는 적지 않습니다**(회사·상품마다 다르고 바뀝니다).
- 수입 약속 없음 · 자격시험/등록 안내 · 「수입은 사람마다 다릅니다」 는 그대로.

```bash

node tools/snap-ba.js  /tmp/ba 1700 1200 sHd s1 s0 r_all sFam sTrust   # 보장 전·후 발표 장 (1장에 30초~1분)

node tools/snap-report.js /tmp/rp 7 9 15 18                                # 치료 한 바퀴 보고서 장 (사진까지 · 보험사 이름 가림)
node tools/snap-page.js /tmp/x app/finance.html 900 2600 "finSample();switchTab('pension');renderPensionSim()" "#pension-sim" pension
```

찍은 것을 jpg 로 바꿔 `shots/` 에 둡니다(`ba_<id>.jpg` · `keep4_1~3.jpg` — 긴 그림은 6,000px 씩 잘라 둡니다.
한 장이 너무 길면 브라우저가 못 그려 하얗게 나옵니다). 장을 바꾸려면 `story.html` 의 `DECK` 을 고칩니다.

**일부러 안 쓴 화면** — 상품전략기(「판매인 교육용 · 고객 제시 불가」 · 실제 상품 이름), 거절 근육 훈련(다른 강사 이름),
발표 안의 「암 — 치료 한 바퀴」 장(사진이 비어 찍힘 — 대신 `ba-3d.html` 을 직접 찍었습니다).

### 나를 알리기 — `PROFILE`

`story.html` 맨 위 `PROFILE` 한 곳이 소개 카드 · 끝 인사 · D 후킹 · 면담 안내 한 줄(`ask`)을 채웁니다.
값은 앱의 콘텐츠 페르소나(`DEFAULT_PERSONA`)에서 옮겼습니다 — **다르면 고쳐 주십시오.** `handle`(인스타 아이디) · `photo`(정사각 사진)를 넣으면 붙습니다.

⚠ 소속 회사 이름이 나옵니다. 올리기 전에 회사 광고 심의(준법감시)를 거치십시오.

## 일부러 안 넣은 것

- **수입 숫자·「월 ○○○ 보장」 같은 말.** 모집 광고에서 소득을 장담하면 거짓·과장 구인광고가
  되고, 지원자가 와서 처음 듣는 말이 「그건 아니고요」가 됩니다. 대신 그 자리를
  **「수입은 약속 안 한다. 무기는 약속한다.」** 로 뒤집었습니다. 영상에서 제일 센 한 방이 이 줄입니다.
- **지어낸 후기·가짜 사례.** 폰 화면은 「예시 화면」 표시를 달았고, 견본 이름은 홍길동, 나머지는 김○○처럼
  가렸습니다. 금액은 하나도 적지 않았습니다.
- **남의 음원.** 비트는 `beat.py` 가 직접 합성합니다. 저작권 문제가 없어 광고로 돌려도 됩니다.
  인스타 앱에서 유행 음원을 덧입히고 싶으면 원래 소리를 줄이고 올리시면 됩니다.

맨 끝 작은 글씨 두 줄(자격시험·등록 절차가 필요하다, 수입은 사람마다 다르다)은 빼지 마십시오.
**올리기 전에 소속 회사의 광고 심의(준법감시)를 한 번 거치십시오.**

## 타깃팅 요령

- **사람은 영상이 고릅니다.** 채용 광고는 플랫폼에 따라 나이·성별 타깃이 막히기도 합니다.
  그래서 첫 3초를 셋으로 나눴습니다 — 「월급」 에 멈추는 사람, 「하원 시간」 에 멈추는 사람,
  「감으로 영업」 에 멈추는 사람은 서로 다릅니다.
- 셋을 같은 예산으로 2~3일 돌리고 **3초 시청률·댓글 「무기」 수**로 이긴 쪽을 남기십시오.
  지는 버전은 후킹 글만 바꿔 다시 굽습니다(아래).
- 댓글 「무기」 → DM 자동응답(인스타 자동 DM 도구)을 걸어 두면 댓글이 곧 명단이 됩니다.
  DM 에는 다음 단계(설명 자리·면담 일정)를 적되, 여기서도 소득 숫자는 약속하지 마십시오.

## 다시 굽기 · 고치기

```bash
export NODE_PATH=/opt/node22/lib/node_modules
node render.js story    # 끝까지 넷 다 (한 편에 3분 · 두 창에서 나눠 돌리면 빠릅니다)

node render.js          # 글자형 셋 다 (한 편에 1분쯤)
```

- 고비·핵심 한 줄·메뉴 꼬리표는 `story.html` 의 `PAINS` 에, 막막이 움직임은 `CH` 시간표에 있습니다.
- 후킹 글은 `reel.html`·`story.html` 의 `VARIANTS` 에 있습니다. D 를 하나 더 넣고 `render.js` 의 `NAMES` 에
  이름을 붙이면 네 번째 버전이 나옵니다.
- 끝의 「무기」 낱말·브랜드 이름·작은 글씨도 `reel.html` 에서 바로 고칩니다.
- 브라우저에서 `reel.html#A` 를 열고 콘솔에 `render(18.2)` 를 치면 그 순간 화면을 볼 수 있습니다.
- 글꼴은 Pretendard(공개 글꼴, jsdelivr) 를 받아 씁니다.
