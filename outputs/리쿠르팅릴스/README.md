# 설계사 리쿠르팅 릴스 — 세로 1080×1920 · 30fps

두 가지 판이 있습니다.

| 판 | 길이 | 파일 | 소스 |
|---|---|---|---|
| **이야기형 (막막이)** | 37.5초 | `out/스토리릴스_*.mp4` | `story.html` |
| 글자형 | 23.5초 | `out/리쿠르팅릴스_*.mp4` | `reel.html` |

## 이야기형 — 막막이가 다섯 고비를 넘는다

신입 설계사 캐릭터 「막막이」(직접 그린 SVG)가 영업의 다섯 고비에서 막히고, 앱 메뉴로 넘깁니다.
고비마다 **고민 1.75초 → 해법 2.75초**. 고민 때는 화면이 붉어지고 비트가 가라앉으며 「어-오」,
해법 때는 종소리와 함께 앱 화면이 떨어지고 핵심 한 줄이 꽂힙니다.

| 고비 | 막막이의 고민 | 핵심 한 줄 | 앱 메뉴(실제 이름) |
|---|---|---|---|
| 1 찾기 | 만날 사람이 없어… | 누굴·어디서 만날지 앱이 짜 준다 | DB 통합 CRM · 지역 동선 · 미끼상품 접촉전략 |
| 2 연락 | 전화 걸기가 무서워… | 첫 마디는 대본에, 거절은 연습으로 | TA 스크립트 · 거절 근육 훈련 · 신입 TA 교육 |
| 3 상담 | 질문 하나에 머리가 하얘져 | 답은 약관 원문에서, 형광펜까지 | 상품전략기 · 재무설계 실전화법서 · AI 상담 어시스턴트 |
| 4 제안 | 분석·제안서에 밤샌다 | PDF 넣으면 전·후가 한 장에 | AI 보장분석 · 보장분석 전&후 만들기 · AI 제안서 생성 |
| 5 관리 | 계약 뒤가 더 막막해 | 챙길 날은 앱이 먼저 부른다 | 오늘의 AI 비서 · 4년 유지관리 · 청구·사후관리 |

끝은 **막막이 → 척척이**(명찰이 바뀌고 선글라스) · 찾기·연락·상담·제안·관리 ✔ ·
「처음부터 끝까지, 앱 하나.」 → 「수입은 약속 안 한다. 무기는 약속한다.」 → 댓글 「무기」.

⚠ 고비 1 의 「앱이 짜 준다」는 **DB 를 넣으면** 동선을 짜 준다는 뜻입니다. 신입에게 DB 를 배정하는지는
회사 방침이니, 배정하지 않으면 DM·설명 자리에서 그 점을 분명히 하십시오.

# 글자형 — 23.5초

영상 세 편은 **처음 3초(후킹)만 다르고** 나머지는 같습니다. 셋을 함께 올리고 반응이
좋은 쪽에 광고비를 몰아주는 A/B 용입니다.

| 파일 | 노리는 사람 | 처음 3초 |
|---|---|---|
| `out/리쿠르팅릴스_A_직장인.mp4` | 20~30대 직장인 · 이직 고민 | **월급 빼고 다 오른다.** — 언제까지 버틸 건데? |
| `out/리쿠르팅릴스_B_육아맘.mp4` | 30~40대 · 경력 단절 · 육아 | **아이 하원 시간, 내가 정하는 직업.** — …있긴 할까? |
| `out/리쿠르팅릴스_C_경력설계사.mp4` | 영업 경험자 · 다른 곳 설계사 | **아직도 감으로 영업해?** — 엑셀·메모장·기억력으로? |

표지(썸네일)는 `out/표지_리쿠르팅릴스_*.jpg` · `out/표지_스토리릴스_*.jpg` 입니다.

## 흐름 (120 BPM · 컷은 박자에 맞춤)

| 초 | 장면 |
|---|---|
| 0–3 | 후킹 (버전마다 다름) |
| 3–5.5 | 보험설계사 = 지인 영업? → **✕ 옛날 얘기** 도장 |
| 5.5–7.5 | 우리는 **무기부터** 준다. |
| 7.5–14 | 폰 화면 넷 — 보장분석 전·후 / 제안서 한 장 / 재무 계산기 / 오늘 할 일 |
| 14–16.5 | 처음이어도 괜찮다. — 보험아카데미 · 실전 화법서 · 코칭 |
| 16.5–19.5 | 수입은 약속 **안** 한다. (소리 멈춤) → **무기는 약속한다.** |
| 19.5–23.5 | 댓글에 「무기」 남기면 DM — 아래에 작은 안내 두 줄 |

## 일부러 안 넣은 것

- **수입 숫자·「월 ○○○ 보장」 같은 말.** 모집 광고에서 소득을 장담하면 거짓·과장 구인광고가
  되고, 지원자가 와서 처음 듣는 말이 「그건 아니고요」가 됩니다. 대신 그 자리를
  **「수입은 약속 안 한다. 무기는 약속한다.」** 로 뒤집었습니다. 영상에서 제일 센 한 방이 이 줄입니다.
- **지어낸 후기·가짜 사례.** 폰 화면은 「예시 화면」 표시를 달았고, 견본 이름은 홍길동, 나머지는 김○○처럼
  가렸습니다. 금액은 하나도 적지 않았습니다.
- **남의 음원.** 비트는 `beat.py` 가 직접 합성합니다. 저작권 문제가 없어 광고로 돌려도 됩니다.
  인스타 앱에서 유행 음원을 덧입히고 싶으면 원래 소리를 줄이고 올리시면 됩니다.

맨 끝 작은 글씨 두 줄(자격시험·등록 절차가 필요하다, 수입은 사람마다 다르다)은 빼지 마십시오.
**올리기 전에 소속 회사의 광고 심의(준법감시)를 한 번 거치십시오.**

## 올릴 때 캡션 (복사용)

```
보험설계사 = 지인 영업?
그건 옛날 얘기입니다.

우리는 첫날부터 '무기'를 드립니다.
✔ 보장분석 전·후를 한 화면에
✔ 고객 앞에서 바로 뽑는 제안서
✔ 재무 계산기 · 오늘 할 일 정리
✔ 처음이어도 — 아카데미 · 실전 화법서 · 코칭

수입은 약속하지 않습니다. 무기는 약속합니다.
궁금하면 댓글에 「무기」 👇 DM으로 자세히 알려드릴게요.

※ 보험설계사로 일하려면 자격시험 합격과 등록 절차가 필요합니다.
※ 수입은 활동과 성과에 따라 사람마다 다릅니다.

#보험설계사 #설계사모집 #이직 #직업추천 #워킹맘 #경력단절 #영업직 #APEX
```

B(육아맘) 버전은 첫 줄을 `아이 하원 시간, 내가 정하는 직업 — 있긴 할까?` 로,
C(경력설계사) 버전은 `아직도 감으로 영업하세요?` 로 바꿔 쓰면 영상과 이어집니다.

## 타깃팅 요령

- **사람은 영상이 고릅니다.** 채용 광고는 플랫폼에 따라 나이·성별 타깃이 막히기도 합니다.
  그래서 첫 3초를 셋으로 나눴습니다 — 「월급」 에 멈추는 사람, 「하원 시간」 에 멈추는 사람,
  「감으로 영업」 에 멈추는 사람은 서로 다릅니다.
- 셋을 같은 예산으로 2~3일 돌리고 **3초 시청률·댓글 「무기」 수**로 이긴 쪽을 남기십시오.
  지는 버전은 후킹 글만 바꿔 다시 굽습니다(아래).
- 댓글 「무기」 → DM 자동응답(인스타 자동 DM 도구)을 걸어 두면 댓글이 곧 명단이 됩니다.
  DM 에는 다음 단계(설명 자리·면담 일정)를 적되, 여기서도 소득 숫자는 약속하지 마십시오.

## 다시 굽기 · 고치기

```bash
export NODE_PATH=/opt/node22/lib/node_modules
node render.js story    # 이야기형 셋 다 (한 편에 2분쯤)
node render.js story B  # 이야기형 B 만
node render.js          # 글자형 셋 다 (한 편에 1분쯤)
```

- 고비·핵심 한 줄·메뉴 꼬리표는 `story.html` 의 `PAINS` 에, 막막이 움직임은 `CH` 시간표에 있습니다.
- 후킹 글은 `reel.html`·`story.html` 의 `VARIANTS` 에 있습니다. D 를 하나 더 넣고 `render.js` 의 `NAMES` 에
  이름을 붙이면 네 번째 버전이 나옵니다.
- 끝의 「무기」 낱말·브랜드 이름·작은 글씨도 `reel.html` 에서 바로 고칩니다.
- 브라우저에서 `reel.html#A` 를 열고 콘솔에 `render(18.2)` 를 치면 그 순간 화면을 볼 수 있습니다.
- 글꼴은 Pretendard(공개 글꼴, jsdelivr) 를 받아 씁니다.
