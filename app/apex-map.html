자비스에게 머리를 달아 주기

키를 넣지 않아도 자비스는 지도에 담긴 것(화면과 순서표)을 그대로 안내합니다. 키를 넣으면 그 위에 AI 가 붙어서, 적어 주신 상황을 읽고 직접 답하고 방향까지 찾아 줍니다. 구글(Gemini)은 무료 키로도 됩니다.

공짜로 쓰실 수 있습니다 aistudio.google.com/apikey 에서 구글 계정으로 로그인 → Create API key → AIza… 로 시작하는 글자를 복사해 아래에 붙여 넣으면 끝입니다. 카드 등록이 필요 없습니다. · 무료라서 한도가 있습니다. 다 쓰면 잠시 뒤 다시 되거나, 회사 서버로 넘기면 됩니다. · 무료 키로 보낸 글은 구글 학습에 쓰일 수 있습니다 — 고객 이름·병력·연락처는 적지 마세요. 그런 이야기는 회사 서버 칸을 쓰십시오.
키는 이 브라우저에만 저장되고 다른 곳으로 보내지 않습니다. 발급은 console.anthropic.com → API Keys 에서 하고, Billing 에 월 상한을 걸어 두면 과금 걱정이 없습니다. 쓴 만큼 요금이 나갑니다.
