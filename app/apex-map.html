공짜로 쓰실 수 있습니다 aistudio.google.com/apikey 에서 구글 계정으로 로그인 → Create API key → AIza… 로 시작하는 글자를 복사해 아래에 붙여 넣으면 끝입니다. 카드 등록이 필요 없습니다. · 무료라서 한도가 있습니다. 다 쓰면 잠시 뒤 다시 되거나, 회사 서버로 넘기면 됩니다. · 무료 키로 보낸 글은 구글 학습에 쓰일 수 있습니다 — 고객 이름·병력·연락처는 적지 마세요. 그런 이야기는 회사 서버 칸을 쓰십시오.
