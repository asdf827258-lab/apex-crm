시세 화면과 자동매매 봇을 한 곳에 모은 구역입니다.

| 주소 | 파일 | 무엇 |
|---|---|---|
| **`/trading/todo`** | `trading/todo.html` | **할 일 10개 — 버튼 누르고 명령어 복사만 하면 되는 체크리스트** |
| `/trading/` | `trading/index.html` | 트레이딩 데스크 — 시세 화면 + 자동매매 콘솔 |

## 지금 상태

**된 것**

- 데스크 화면 전체 — 지수 카드, 실시간 차트 표, 계좌 사이드바, 하단 티커
- 자동매매 콘솔 — 3중 잠금 표시, 위험 슬라이더, 전략 토글, 감시 종목, 신호 로그
- 시세 표에서 `+봇` 을 누르면 그 종목이 봇 감시 목록에 들어갑니다
- 위험 슬라이더가 수량을 실시간으로 다시 계산합니다 (봇의 1% 룰과 같은 식)
- `/api/market` 프록시 연결 — 키가 있으면 실시간, 없으면 표본값 유지
- 파이썬 봇 전체가 저장소 안으로 들어왔습니다 (전에는 컨테이너에만 있었습니다)

**안 된 것 — 형님만 할 수 있는 것**

아래 세 가지는 키가 필요해서 제가 대신 할 수 없습니다.

## ① 화면에 실제 시세 붙이기

지금 데스크 화면 좌측 상단에 **`표본 데이터`** 라고 떠 있습니다. 실제 시세가
들어오면 초록색 **`실시간 시세`** 로 바뀝니다.

Netlify → Site settings → Environment variables 에 아래 중 **하나만** 넣으면 됩니다.

| 넣는 것 | 무엇 | 승인 |
|---|---|---|
| `DATA_GO_KR_KEY` | 공공데이터포털 금융위원회 시세 | **자동승인 · 제일 빠름** (대신 전일 종가) |
| `KIS_APP_KEY` + `KIS_APP_SECRET` | 한국투자증권 | 계좌 필요 · 실시간 |
| `TOSS_CLIENT_ID` + `TOSS_CLIENT_SECRET` | 토스증권 오픈API | 신청·승인 필요 · 실시간 |

넣고 나서 `/api/market?kind=health` 를 열면 무엇이 꽂혔는지 알려줍니다.

> 당장 화면만 보고 싶으시면 `DATA_GO_KR_KEY` 하나만 받으세요. 자동승인이고
> 증권 계좌도 필요 없습니다. 전일 종가라 장중 숫자는 안 움직입니다.

`SHARED_TOKEN` 을 서버에 걸어두셨다면, 앱 **설정 → AI 연결 → 공유 토큰** 칸에
같은 값이 들어가 있어야 이 화면도 통과합니다 (같은 브라우저 저장소를 씁니다).

## ② 봇을 실제로 돌리기

```bash
cd paper-trading-bot
bash setup.sh                 # 가상환경 + 패키지
cp .env.example .env          # 여기에 키를 넣습니다
```

`.env` 에 넣을 것 — **[Alpaca](https://alpaca.markets) 에서 무료로 발급됩니다.
모의투자 계좌는 신분증도 입금도 필요 없습니다.**

```
ALPACA_API_KEY=...
ALPACA_SECRET_KEY=...
```

그 다음:

```bash
python main.py status              # 키가 제대로 꽂혔는지
python main.py paper --dry-run     # 주문 안 내고 계획만
python main.py backtest --months 6 # 진짜 시세로 백테스트
```

`.env` 는 `.gitignore` 에 들어 있어서 절대 커밋되지 않습니다.

## ③ 백테스트 관문 다시 보기

지금까지 나온 백테스트 숫자는 **전부 합성 데이터(`--synthetic`)** 라 의미가 없습니다.
순수 랜덤워크에서는 평균회귀가 비용만큼 잃는 게 정상입니다.

키를 넣고 `--synthetic` **없이** 돌리면 진짜 판정이 나옵니다. 맨 아래 관문 다섯 개 중
**하나라도 ❌ 면 모의투자로 넘어가면 안 됩니다.**

| 관문 | 기준 |
|---|---|
| 거래가 실제로 발생했는가 | 0건이면 전략이 안 돈 것 |
| 최대 낙폭 | 15% 이하 |
| 샤프 지수 | 양수 |
| 비용이 0 이 아닌가 | 수수료·슬리피지가 빠졌으면 거짓말 |
| 한 자산에 쏠리지 않았는가 | 한 종목이 손익 전부면 우연 |

## 실계좌는 어떻게 열리나

세 개가 **동시에** 있어야 열립니다. 하나라도 없으면 조용히 실패하지 않고,
**모의로 내려간 뒤 무엇이 빠졌는지 알려줍니다.**

```
.env   ALPACA_PAPER=false
.env   ALPACA_LIVE_CONFIRM=I_UNDERSTAND_REAL_MONEY
명령줄  --live
```

여덟 조합(2×2×2)을 전부 도는 테스트가 있고, **정확히 한 줄만 실계좌**인지 셉니다
(`tests/test_live_requires_triple_confirm.py`).

## 주의

- `GLD`·`USO` 는 금·원유가 아니라 **ETF 대리 자산**입니다. 특히 `USO` 는 선물을
  굴리는 구조라 유가가 제자리여도 가격이 깎일 수 있습니다. 백테스트 성과를
  원자재 성과로 읽으면 안 됩니다.
- 과거에 통했다고 앞으로 통한다는 보장은 없습니다.
- 데스크 화면의 계좌·보유 종목 숫자는 **화면 구조를 보여주는 표본값**입니다.
  실제 계좌 잔고가 아닙니다.
