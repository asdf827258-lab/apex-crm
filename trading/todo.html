03공공데이터포털 키 하나 받아 넣기

자동승인이라 신청하면 바로 나옵니다. 증권 계좌도, IP 등록도 필요 없습니다. 활용신청 → 마이페이지 › 개발계정에서 일반 인증키(Decoding) 복사.

i
Key 칸엔 위 이름, Values 칸엔 실제 키. 넣고 나면 Deploys → Trigger deploy 를 한 번 눌러야 함수가 새 값을 읽습니다.

전일 종가라 장중엔 숫자가 안 움직입니다. 실시간이 필요해지면 그때 KIS_APP_KEY / KIS_APP_SECRET (한국투자증권)으로 올리면 됩니다 — IP 등록이 없고 지수까지 줍니다.
