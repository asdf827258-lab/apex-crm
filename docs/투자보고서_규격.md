# 아침 투자 브리핑 — 무엇을 모으고, 어떻게 쓰는가

매 영업일 **KST 07:00** 에 서버가 계좌별로 한 장씩 만들어 둡니다.
아침에 앱 → **오늘의 AI 비서** 를 열면 이미 있습니다.

---

## 1. `.env` 어떻게 넣는가

`.env` 는 **형님 컴퓨터의 `paper-trading-bot/` 폴더 안**에 만드는 파일입니다.
Netlify 가 아닙니다 — 봇은 서버가 아니라 형님 컴퓨터에서 돕니다.

### 만들기

```bash
cd paper-trading-bot
cp .env.example .env
```

이러면 `.env` 파일이 생깁니다. 그걸 **메모장이나 편집기로 열어서** 값만 바꾸면 됩니다.

### 형식 — 딱 세 가지만 지키면 됩니다

```
이름=값
```

1. **`=` 앞뒤에 공백을 넣지 마세요.** `KIS_APP_KEY = abc` (✗) / `KIS_APP_KEY=abc` (○)
2. **값에 따옴표를 붙이지 마세요.** `KIS_APP_KEY="abc"` (✗) / `KIS_APP_KEY=abc` (○)
3. **`#` 으로 시작하는 줄은 설명입니다.** 그 줄은 무시됩니다.

### 실제로 이렇게 됩니다

```
# ── 미국 (Alpaca) ──
ALPACA_API_KEY=PK7XXXXXXXXXXXXXXXXX
ALPACA_SECRET_KEY=abcdefghijklmnopqrstuvwxyz1234567890ABCD
ALPACA_PAPER=true

# ── 국내 (한국투자증권) ──
KIS_APP_KEY=PSxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
KIS_APP_SECRET=yyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyy
KIS_ACCOUNT=12345678-01
KIS_PAPER=true

# ── 리포트 전송 (선택) ──
REPORT_WEBHOOK_URL=
```

### 넣었는지 확인

```bash
python main.py status        # 미국
python main.py kis status    # 국내
```

**키가 있으면 `PS12********(길이 36)` 처럼 앞 4자만 보입니다.** 값이 그대로 찍히면 안 됩니다.
없으면 **뭐가 빠졌는지 이름을 알려줍니다.**

> ⚠️ `.env` 는 `.gitignore` 에 들어 있어 **깃에 절대 올라가지 않습니다.**
> 그래도 커밋 전에 `git status` 로 한 번 확인하는 습관이 안전합니다.
> `.env.example` 은 예시라 올라가도 됩니다 — **거기엔 진짜 키를 적지 마세요.**

## 2. 무엇을 모으는가

| 출처 | 담는 것 | 없으면 |
|---|---|---|
| `invest_nav` | 어제·그제 평가액 → **어제 대비 손익** | 2일치 미만이면 그 계좌는 건너뜀 |
| `invest_nav` (전체) | 최고점 → **낙폭**, 정지선까지 여유 | — |
| `invest_holdings` + `invest_prices` | **많이 움직인 종목** 상위 3 | "확인 안 됨" |
| `invest_targets` | **목표 배분 이탈** | "설정 안 됨" |
| `invest_txns` | **어제 체결** | "없음" |
| `invest_signals` | **봇 신호**(모의) | "없음" |
| `econ_indicators` (`usdkrw`) | 달러 종목 원화 환산 | USD 종목을 배분에서 **빼고 그렇다고 적음** |

계산은 `scripts/perf-core.js` 하나만 씁니다 — **앱 화면과 같은 계산기**라
"화면 숫자와 리포트 숫자가 다르다" 는 사고가 생기지 않습니다.

## 3. 감사에서 고친 것 4가지

양식을 다듬기 전에 **무엇을 모으는지부터** 확인했습니다. 셋이 틀렸고 하나가 빠져 있었습니다.

### ① 봇 신호를 영원히 못 찾고 있었다

07시에 돌면서 **어제 장**을 보고하는데 신호를 **오늘 날짜**로 찾고 있었습니다.
신호는 어제 났으니 0건입니다. 늘 "신호 없음"이라고 적었고, **진짜 없어서인지
못 찾아서인지 구분이 안 됐습니다.** 자료의 기준일로 찾도록 고쳤습니다.

### ② 며칠 전 등락을 "어제"라고 말할 수 있었다

야간 수집이 하루라도 걸러지면 시세가 옛날 것으로 남는데, 그걸 그대로
"어제 많이 움직인 종목"이라고 적었습니다. 이제 기준일이 다르면 이렇게 나옵니다:

```
· 많이 움직인 종목(2026-08-10 기준 · 어제 자료 아님): 삼성전자 +2.41% …
```

### ③ 시세 600행 창이 종목을 잘라먹을 수 있었다

최신 600행을 받아 그중 최신일만 걸렀습니다. 여러 날이 섞이면 최신일 종목 일부가
창 밖으로 밀립니다. **조용히 몇 종목만 빠지는 쪽이 한눈에 안 보여 더 나쁩니다.**
최신 날짜를 먼저 확인한 뒤 그 날짜만 집어서 받고, 받은 종목 수를 로그에 남깁니다.

### ④ 어제 뭘 사고팔았는지가 없었다

신호(계획)는 있는데 체결(사실)이 없었습니다. **둘은 다른 정보입니다** —
신호가 났다고 산 게 아닙니다. `invest_txns` 를 읽어 "어제 체결"을 넣었습니다.

## 4. 보고서 양식 — 실제 출력

아래는 가짜 계좌로 **실제로 돌려서 나온 출력**입니다.

```
## 2026-08-14 아침 브리핑

[2026-08-14 일간 · 윤대표 주식계좌]
· 평가금액: 9,948,000원 (기준일 2026-08-13)
· 어제 대비: +448,000원 (+4.72%)
· 누적 운용 성과(TWR): +4.7%
· 최고점 대비 낙폭: 0% / 정지선 15% (여유 15%p)
· 어제 많이 움직인 종목: 삼성전자 +2.41% · KODEX 200 −0.62%
· 어제 체결: buy 1,424,000원
· 목표 배분: 설정 안 됨
· 어제 봇 신호 1건(모의): 삼성전자 매수

※ 투자성 상품은 원금손실이 발생할 수 있으며 과거 수익이 미래 수익을 보장하지 않습니다.
```

**AI 키가 있으면** 위 숫자를 근거로 이런 형식의 문장이 더 붙습니다:

```
## 한 줄
## 어제 (2줄)
## 오늘 볼 것 1가지
```

AI 규칙은 이렇게 걸어뒀습니다:

- 주어진 숫자만 쓰고 **없는 수치를 지어내지 않는다**. `—` 는 "확인 안 됨"이라고 쓴다
- **특정 종목의 매수/매도를 권유하지 않는다** — 사실과 점검할 거리만
- **하루 등락으로 호들갑 떨지 않는다** — 하루는 소음이다. 추세와 위험선만
- "무조건·확정 수익" 같은 단정 표현 금지
- **전체 6줄을 넘기지 않는다** — 아침에 읽는 글이다

**AI 키가 없어도** 위 숫자 리포트는 그대로 남습니다. 빈손보다 낫습니다.

## 5. 숫자를 다룰 때 지킨 것

- **하루 수익률은 그날 들어온 돈을 빼고** 잽니다. 입금을 수익으로 세면 안 됩니다
- **USD 종목은 환율로 환산한 뒤** 배분에 넣습니다. 환산 없이 섞으면 애플 15주가
  `3,486` 으로 잡혀 **"해외주식 0%"** 라는 조용히 틀린 숫자가 나옵니다 (실제로 겪은 일)
- **하루 등락은 소수점 두 자리.** 한 자리로 자르면 `3.95%` 가 `4%` 로 보입니다
- **모르는 값은 `0` 이 아니라 `—`.** 0 과 "모름"은 다릅니다

## 6. 언제부터 보이는가

1. 앱에서 보유 종목 넣고 → **서버 저장** (브라우저에만 있으면 서버가 못 읽습니다)
2. 그날 밤 `market-daily` 가 종가를 채우고 (KST 16:10)
3. 다음 날 새벽 `invest-daily` 가 브리핑을 만들고 (KST 07:00)
4. **아침에 앱 → 오늘의 AI 비서** 에 있습니다

**첫 브리핑은 내일 아침**입니다. 어제 대비를 계산하려면 이틀치 평가액이 필요해
**제대로 된 숫자는 모레부터**입니다.

> 주소로는 열 수 없습니다. `netlify.toml` 에 `schedule` 이 걸린 함수는 Netlify 가
> HTTP 호출을 403 으로 막습니다. 손으로 돌려 보시려면
> Netlify → **Functions → invest-daily → Run**.
