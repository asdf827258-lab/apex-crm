디자인이 조금씩 다른 까닭

목각과 본체의 값을 한 속성씩 기계로 재 봤습니다. 눈으로 본 게 아닙니다. 24군데가 다릅니다. 그런데 아무 데나 다른 게 아니라 한 가지 까닭으로 전부 설명됩니다.

찾은 까닭
본체 ui.css 는 폰 목각 값입니다 — 그걸 컴퓨터 화면에도 씁니다 ui.css 머리말에 직접 적혀 있습니다 — 「값은 전부 목업(APEX사본.html)에서 그대로 옮겼습니다」. APEX사본.html 이 폰(390px) 목각입니다.
그래서 1440px 컴퓨터 화면에 폰 치수가 그대로 깔립니다. 글씨는 0.5~1px 씩 작고, 칸은 1~4px 씩 좁습니다. 한 군데씩 보면 「비슷한데?」 싶지만 스물네 군데가 겹치니 화면 전체가 다르게 보입니다. 사장님이 「조금씩 다르다」 하신 게 이것입니다.
고치는 길은 한 줄기입니다. ui.css 는 이미 @media (max-width:900px) 로 폰 예외를 두는 짜임입니다 — 즉 기본값이 넓은 화면 몫입니다. 그러니 넓은 화면에만 PC 목각 값을 덮는 블록 하나를 맨 끝에 붙이면 됩니다. 이름은 하나도 안 바꾸고, 폰은 한 픽셀도 안 변합니다.

제가 목각을 고친 두 줄

44px 은 본체가 옳습니다. ui.css 에 「누르는 것은 최소 44px (철칙)」 이라고 적혀 있고, 그건 사장님이 먼저 정하신 규칙입니다. 제 목각이 38px · 36px 로 그린 것이 틀렸습니다. 목각을 44px 로 올렸습니다 — 작은 단추 · 칩 · 회색 단추 · 폰의 mini 단추.
그래서 이 둘은 본체가 고칠 것이 없습니다. 목각 쪽을 본체에 맞췄습니다.

옮기다 잘못 적힌 것 둘 — 폰도 틀립니다

① 목록 동그라미 모서리
폰 목각도 14px 인데 본체는 13px 입니다 .t-row .av{border-radius:var(--t-r-sm)} 로 적혀 있는데 --t-r-sm 은 13px 입니다. 폰 목각(APEX사본.html)의 .av 는 14px 입니다 — 옮길 때 가까운 토큰으로 붙여 버린 것입니다.
이건 미디어쿼리 밖에서 고쳐야 합니다. 폰에서도 틀린 값이기 때문입니다.
② 알림 상자 글자색
광고심의 색을 빌려 쓰고 있습니다 .t-note{color:var(--t-sealk)} — --t-sealk 는 #8A6A2F, 광고심의가 정한 색입니다. 목각의 알림 글자색은 #8A5A12 로 다릅니다.
S06 에 「--t-seal / --t-sealk 는 광고심의 색 — 건드리지 말 것」 이라고 적혀 있습니다. 건드리지 않는다는 것은 다른 데 갖다 쓰지도 않는다는 뜻입니다. 심의 색이 바뀌면 상관없는 알림 상자까지 같이 바뀝니다. 토큰 하나를 새로 세워야 합니다.

사장님 말씀 : 「목각하고 디자인이 너무 다르다. 아예 똑같이 해 달라.」

잰 결과
  목각(목업_PC.html)과 app/ui.css 를 한 속성씩 기계로 대 봤습니다. 24군데가 다릅니다.
  까닭은 하나입니다 — ui.css 는 폰 목각(APEX사본.html) 값입니다(머리말에 그렇게 적혀 있습니다).
  그 폰 치수를 1440px 컴퓨터 화면에도 그대로 씁니다. 그래서 글씨가 0.5~1px 작고
  칸이 1~4px 좁습니다. 한 군데씩은 티가 안 나는데 스물네 군데가 겹쳐 화면이 달라 보입니다.

고치는 법
  ui.css 는 이미 @media (max-width:900px) 로 폰 예외를 두는 짜임입니다.
  즉 기본값이 넓은 화면 몫입니다. 그러니 맨 끝에 @media (min-width:901px) 블록 하나만
  붙이면 됩니다. 위쪽은 한 줄도 지우지 마십시오. 폰은 한 픽셀도 안 변합니다.
  붙일 CSS 는 사장님이 주신 「디자인_맞추기_점검.html」 의 「붙여 넣을 CSS」 그대로입니다.

  ★ 값은 전부 목업_PC.html 에서 옮긴 것입니다. 새로 정한 값은 없습니다.
  ★ 새 class 를 만들지 않았습니다. 이름도 안 바꿨습니다.
  ★ 44px 철칙은 지킵니다 — 높이는 안 건드립니다.

같이 고칠 것 둘 (미디어쿼리 밖 · 폰에서도 틀립니다)
  ① .t-row .av 의 border-radius 가 var(--t-r-sm)=13px 인데, 폰 목각도 14px 입니다.
