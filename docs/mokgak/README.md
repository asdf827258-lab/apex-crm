# 목각 — 그림(기준) 파일들

여기 있는 파일은 **앱이 아닙니다.** 본체를 어떻게 고칠지 보여 주는 **그림**입니다.
지금까지 이 그림들이 사장님 PC 바탕화면(`Desktop\코드\토스풍_목업`)에만 있어서
클라우드 세션이 「파일이 없다」고 했습니다. 그래서 저장소 안으로 옮겨 둡니다.

`/docs/*` 는 `_redirects` 34줄에서 404 로 막혀 있습니다 — **밖으로는 안 나갑니다.**

## 파일

| 파일 | 무엇 | 언제 봅니까 |
|---|---|---|
| `hansaram.html` | **한 사람 — 고객 365일 + DB 통합 CRM 을 하나로.** 새 판. 화면 11개 · 서랍 6개 | 판 ①~⑤ 를 짤 때 **이것이 기준** |
| `design-diff.html` | 목각과 `app/ui.css` 의 속성 24가지 차이 + **붙여 넣을 `@media (min-width:901px)` 한 덩어리** | 순서 ① 디자인 맞추기 |
| `data-audit.html` | 목각 · 본체 · 폰 세 벌을 60항목으로 대 본 표 | 「이건 이미 본체에 있나?」 할 때 |
| `handoff.html` | 한 판 인계문 (목차 · 5판 · 빠짐없음 점검표 10칸) | 순서를 다시 볼 때 |
| `mokgak-pc.html` | 앞서 만든 컴퓨터 화면 목각 14장 | 옛 그림 대조용 |
| `mokgak-phone.html` | 같은 것의 폰 판 17장 | 폰 화면 맞출 때 |

## 여는 법

브라우저로 열면 바로 돕니다. 서버도 빌드도 필요 없습니다.

    docs/mokgak/hansaram.html

주소 뒤에 붙일 수 있는 것 — `?v=<화면>` 과 `?call=p1`

    hansaram.html?v=list      명단
    hansaram.html?v=one       한 장 (서랍 6개)
    hansaram.html?v=kb        보장분석 붙여넣기
    hansaram.html?call=p1     전화 기록 창이 바로 열림  ← 판 ② 는 이걸 보십시오

화면 이름 11가지 : `today` `list` `one` `ask` `cal` `kb` `stat` `team` `why` `plan` `bone`

브라우저를 못 여는 곳이면 그냥 읽으십시오. 한 파일에 다 들어 있습니다 —
`RES`(결과 다섯) · `vSheet()`(전화 창 세 층) · `TABS`(왼쪽 메뉴 16묶음 83줄) ·
`kbRead`(보장분석 읽기) · `dw()`(서랍 여섯) 을 찾으면 규칙이 그대로 보입니다.

## 지켜야 할 것

- **목각의 가짜 이름 일곱은 본체로 가져가지 않습니다** (CLAUDE.md 3번).
  움직이는 방식만 가져가고 사람 자료는 버립니다.
- 목각은 자기 CSS 를 갖고 있습니다. **그 CSS 를 본체로 옮기지 마십시오.**
  본체는 `app/ui.css` 의 클래스만 씁니다. 목각은 「이렇게 보이면 됩니다」 라는 그림일 뿐입니다.
- 목각을 고칠 일이 생기면 사장님 PC 의 원본과 여기가 갈라집니다.
  여기 것을 고쳤으면 그렇다고 말씀드리십시오.
