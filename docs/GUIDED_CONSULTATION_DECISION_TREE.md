# GUIDED CONSULTATION DECISION TREE

## 시스템 기본 규칙

신입은 화면이 제시하는 질문을 건너뛸 수 있지만, 건너뛴 이유를 기록해야 한다.
고위험 판단은 관리자 승인 전 고객용 리포트에 확정문으로 나타나지 않는다.

### 고객이 무엇을 원하는지 모르는 경우

다음 6개의 질문으로 우선순위를 찾는다.

1. 지금 가장 부담되는 월지출은?
2. 소득이 멈추면 몇 개월 버틸 수 있는가?
3. 병원비보다 더 걱정되는 것은?
4. 은퇴 후 매월 얼마가 필요하다고 생각하는가?
5. 부모 또는 배우자의 돌봄을 누가 할 것인가?
6. 가족에게 남기고 싶은 것과 남기고 싶지 않은 부담은?
