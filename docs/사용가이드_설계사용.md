# APEX YUN PRO — 설계사용 사용가이드 (당장 쓰는 법)

> 이 문서는 윤시현 본부장과 신입 설계사가 **오늘 바로** 프로그램을 켜서 쓰기 위한 실전 매뉴얼이다.
> 기술 용어는 최소화했다. 순서대로 따라 하면 된다.

최종 갱신: 2026-07-20

---

## 0. 5분 준비 (딱 3가지만)

이 프로그램이 "안 되는 것처럼" 보이는 이유는 버그가 아니라, **아래 3개를 아직 안 했기 때문**이다. 실제로 전체 메뉴를 자동 점검했을 때 오류는 0건이었다.

| 안 되는 것처럼 보이는 증상 | 진짜 원인 | 해결 |
|---|---|---|
| AI 글쓰기·분석 버튼이 결과가 안 나옴 | **AI 키가 없음** | ① 아래 "AI 키 넣기" |
| 로그인해도 고객 목록이 비어 있음 | **데이터가 아직 없음** | ② 고객 1명 등록해보기 |
| 로그인이 풀린 것 같음 | **다른 주소(사이트)에서 로그인함** | ③ 항상 같은 주소로 접속 |

이 3개만 하면 100% 정상 동작한다.

### ① AI 키 넣기 (하루 한 번, 5분, 무료로 시작 가능)

AI 글쓰기·보장분석·상담요약 기능은 "두뇌"가 필요하다. 이 두뇌를 빌리는 열쇠가 **API 키**다.

1. **무료로 시작하려면 (Google Gemini):** 브라우저에서 `aistudio.google.com/apikey` 접속 → 구글 로그인 → `Create API Key` → 생성된 키(`AIza...`)를 **복사**.
2. **더 정밀한 상담문서용 (Claude):** `console.anthropic.com` → API Keys → 키 발급(유료, 신용카드 등록 필요).
3. 프로그램의 **왼쪽 맨 아래 설정(⚙️)** 메뉴 → **API 키 입력칸**에 붙여넣기 → 저장.
   - 키는 이 컴퓨터의 브라우저에만 저장된다(localStorage). 서버·소스코드에 절대 안 들어간다.
   - **주의:** 이 키는 비밀번호와 같다. 남에게 화면 공유할 때 설정 화면을 보여주지 말 것.

> **왜 내가(=이 프로그램을 만든 AI가) 직접 키를 안 넣어주나?**
> 키·비밀번호는 대표님 계정의 돈과 데이터에 직접 연결된다. 안전을 위해 **키 입력은 반드시 사람이 직접** 한다. 이건 대표님을 보호하는 규칙이다.

### ② 로그인 (같은 주소 유지가 핵심)

- 프로그램 우측 상단 **로그인 버튼** → 이메일·비밀번호 입력.
- 계정이 없으면 **회원가입** → 이름·이메일·비밀번호 → 가입.
- **핵심:** 로그인은 "접속한 주소(사이트)마다 따로" 저장된다. `localhost`에서 가입하면 `netlify` 주소에는 로그인이 없다. **항상 같은 즐겨찾기 하나만** 쓸 것. (배포 주소는 `docs/reference_apex_crm` 참조 또는 대표님이 쓰는 즐겨찾기 1개로 통일.)

### ③ 첫 고객 1명 등록 (데이터가 있어야 화면이 채워진다)

- 로그인 후 **고객관리** → **고객 등록** → 이름/연락처 최소 입력 → 저장.
- 이제 대시보드·보장분석·상담 메뉴가 살아난다. (등록 전에는 당연히 비어 있는 게 정상이다.)

## 1. 프로그램 켜는 법

### 배포본을 쓰는 경우 (권장)
대표님이 쓰는 즐겨찾기 주소를 클릭 → 끝. (인터넷만 되면 어디서든, 스마트폰 카카오톡 인앱 브라우저에서도 열림.)

### 내 컴퓨터에서 직접 여는 경우 (개발/점검용)
1. 프로그램 폴더에서 명령창을 열고: `python -m http.server 4176 --directory app`
2. 브라우저에서 `http://localhost:4176` 접속.
3. (이 방식은 점검용. 실사용·판매는 배포본으로.)

## 2. 화면 구조 한눈에

- **왼쪽 사이드바:** 18개 그룹 / 48개 메뉴. 크게 4덩어리다.
  1. **재무설계·계산기** — 키 없이 즉시 동작 (오프라인에서도 됨)
  2. **AI 콘텐츠·마케팅** — 블로그·카톡·광고 글쓰기 (AI 키 필요)
  3. **상담 OS** — 8통장 진단·가이드 상담·보장분석·청구·지급사례 (로그인+키)
  4. **90일 아카데미·관리** — 신입교육·감사로그·본부장 관리 (로그인)
- **오른쪽 하단 재무설계 복귀 버튼:** 재무설계 화면에서 원래대로 돌아오기(Esc도 됨).

## 3. 메뉴별 사용법 (자주 쓰는 순서)

### A. 재무설계 현금흐름표 — **키·로그인 불필요, 상담의 핵심**
- 메뉴에서 **재무설계** 선택 → 전용 화면으로 전환.
- 고객의 소득·지출·자산·부채·은퇴시점을 입력하면 **VIP 현금흐름표**가 자동 계산된다.
- 상담 자리에서 고객과 마주 보고 숫자를 같이 채워 넣는 용도. 결과를 인쇄해 A4로 전달 가능.
- **가장 강력한 무기.** 상품 얘기 전에 이 표부터 같이 그린다.

### B. 8통장 진단지도 — **상담 오프닝**
- 생활·병원비·치료비·소득공백·가족보호·은퇴연금·간병장기요양·자산이전 8개를 셀프 진단(미흡/보통/충분).
- 약한 통장이 자동으로 위에 뜬다 → 오늘 상담에서 다룰 "핵심 공백 최대 3개"를 여기서 고른다.
- AI 종합진단 버튼(키 필요)은 우선순위와 연결관계를 요약해준다. **단, 지급/수익을 보장하는 말은 하지 않는다.**

### C. 가이드 상담 위저드 (보험 해석 탭) — **신입도 상담 진행 가능**
- 고객의 첫 목표를 고른다: 청구 / 절감 / 은퇴 / 간병 / 모름.
- 목표별로 질문이 한 문장씩, "왜 이 질문을 하는지"와 함께 나온다.
- 질문을 건너뛰면 **건너뛴 이유를 반드시 기록**해야 한다(준법).
- 마지막에 AI가 핵심문제 ≤3개·다음 행동·고위험 승인 필요 여부를 요약. 고객 진입 시 상담기록이 저장된다.

### D. 보장분석 (PDF 4단계) — **가입증권 정밀분석**
1. 고객 보험 PDF를 드래그해 업로드(체크섬으로 중복 자동감지).
2. **담보 추출** → AI가 페이지 출처와 함께 사실만 뽑아낸다(추측 금지, 못 읽은 숫자는 null).
3. **검수** → 대표님이 표준명·금액·분류를 교정하고 승인. (승인 전에는 고객에게 안 나간다.)
4. **분석** → 강점 먼저 → 공백·중복·구조위험 → 8통장 충족도 → 계약별 유지/보완/해지 판단 → A/B/C 시나리오.
5. **결과물 4종:** 설계사 정밀리포트 / 고객 A4 1장 / 카톡 설명 / 상담 스크립트. 복사·인쇄 가능.

### E. 청구·지급사례 — **신뢰의 근거**
- 익명화된 지급사례 라이브러리(검증등급 A/B/C/D/X). **X등급은 외부 사용 금지**로 자동 잠긴다.
- 고객 상황과 관련된 사례 1~2개만 골라 설명. **"이만큼 준다"가 아니라 "이런 구조로 작동한다"**로 쓴다.
- 청구 접수 도우미: 필요 서류 체크리스트·미청구 담보 후보를 뽑아준다(지급액은 확정하지 않음).

### F. AI 콘텐츠·마케팅 — **자기 홍보 자동화**
- 블로그 초안·카톡 안내·메타광고 문구·소상공인 답글 등. AI 키만 있으면 즉시.
- **모든 출력은 게시 전 준법감시 확인 안내**가 붙는다. 그대로 올리지 말고 한 번 검토 후 게시.

### G. 90일 아카데미 — **신입 교육**
- 3개월 12주 커리큘럼 + 오늘의 루틴 7종(매일 체크, 자정 초기화) + 개념 퀴즈 12문.
- 퀴즈는 정답이 아니라 **"왜"를 가르친다.** 오답도 근거를 보여준다.
- 진행률은 이 컴퓨터에 저장된다.

### H. 실무 계산기 — **키 불필요**
- 보험나이·BMI·일할계산·일정 + 연금 소득공백·간병요양 자금·상속세 개산.
- 개산(어림계산) 결과에는 면책 문구가 붙는다. 확정 금액이 아님을 고객에게 반드시 안내.

### I. 본부장 관리·감사로그 — **관리자 전용**
- 피드백 → AI 규칙후보 → 승인 → 다음 분석에 반영되는 학습루프.
- 누가 언제 무슨 작업을 했는지 감사로그로 확인(민감정보는 기록 안 함).

## 5. 준법·안전 체크 (매 상담 필수)

- [ ] 고객정보 활용 **동의**를 받았는가.
- [ ] "무조건·확정·보장" 같은 **단정 표현**을 쓰지 않았는가.
- [ ] 지급사례를 **"이만큼 준다"로 오해**시키지 않았는가(구조 설명 목적).
- [ ] 고위험 제안(기존계약 해지 등)은 **관리자 승인** 전 고객에게 확정문으로 전달하지 않았는가.
- [ ] 개산·AI 결과에 **면책 문구**가 포함되어 있는가.
- [ ] AI가 만든 숫자를 **원문·출처로 검증**했는가.
- [ ] 화면 공유 시 **API 키·비밀번호**가 노출되지 않았는가.

## 6. 자주 겪는 문제 (셀프 해결)

| 증상 | 해결 |
|---|---|
| AI 버튼 눌러도 무응답 | 설정에서 키 저장됐는지 확인. 무료 키(Gemini)로 먼저 테스트. |
| "키가 유효하지 않음" | 키 앞뒤 공백 없이 다시 붙여넣기. 새 키 재발급. |
| 로그인이 자꾸 풀림 | 항상 같은 주소(즐겨찾기 1개)로 접속. 시크릿창은 매번 로그아웃됨. |
| 고객 목록이 빔 | 로그인했는지 + 고객 등록했는지 확인. 다른 주소에서 등록했을 수 있음. |
| PDF가 안 읽힘 | 스캔(이미지) PDF는 텍스트가 없을 수 있음. 텍스트 PDF 권장. |
| 재무설계 화면에서 못 빠져나옴 | 우측 하단 복귀 버튼 또는 Esc. |
| 카톡에서 화면이 깨짐 | 카톡 인앱브라우저 대신 우측 상단 "다른 브라우저로 열기". |

## 7. 이 프로그램의 한 줄 정체성

> **상품 자동판매기가 아니라, "질문 → 계산 → 판단 → 설명 → 후속관리"를 표준화한 상담 OS.**
> 신입도 이 순서만 따라가면 대표님과 비슷한 품질의 상담을 진행하고, 관리자가 안전하게 검수한다.

키 하나만 넣으면 오늘부터 전 기능이 열린다.
