# APEX FINANCIAL ADVISOR OS — 연금부터 재가급여까지

## 1. 목표

신입 설계사가 입사 3개월 후 다음 수준에 도달하도록 한다.

- 상품부터 설명하지 않고 고객의 삶과 현금흐름을 먼저 질문한다.
- 보험·연금·노후·간병·상속을 하나의 시간축으로 연결한다.
- PDF와 고객 입력을 기반으로 숫자를 계산하고 근거를 보여준다.
- 실제 보험금 지급사례를 과장 없이 상담의 신뢰 근거로 활용한다.
- 본인이 모르는 내용은 추측하지 않고 확인 항목으로 남긴다.
- 관리자 검수 없이 고위험 제안이 고객에게 발송되지 않게 한다.

이 시스템은 상품 자동판매기가 아니라 **질문·계산·판단·설명·후속관리 표준화 도구**다.

## 2. 상담의 전체 지도 — 8개의 재무 통장

### ① 생활 통장

- 월소득
- 월고정지출
- 변동지출
- 대출상환
- 비상자금
- 저축 가능액

질문:
- 소득이 3개월 멈추면 지금 생활이 유지되는가?
- 당장 사용할 수 있는 현금이 몇 개월치인가?
- 보험료 때문에 저축이 막히고 있지 않은가?

### ② 병원비 통장

- 실손 세대
- 자기부담
- 급여·비급여
- 3대 비급여
- 면책·보장 제외
- 실손 청구 이력

지급사례는 “실손이 무조건 많이 준다”가 아니라, 실제 병원비와 자기부담 구조를 설명하기 위해 사용한다.

### ③ 치료비 통장

- 암·뇌·심장 진단
- 질병·상해 수술
- 항암·방사선·표적·면역
- 혈전용해·제거·시술
- 중환자실
- 반복 치료

한 번의 수술에서 실손과 여러 정액특약이 각각 작동할 수 있음을 실제 지급사례로 설명한다.

### ④ 소득공백 통장

- 월생활비
- 대출
- 사업장 고정비
- 회복기간
- 배우자 소득
- 회사 복지
- 진단비·후유장해

진단비는 병원비가 아니라 일을 쉬는 시간의 생활비로 재해석한다.

### ⑤ 가족보호 통장

- 사망 시 필요자금
- 자녀 교육비
- 대출상환
- 배우자 생활비
- 장례·상속정리비
- 종신·정기보험의 목적

사망보험금의 크기보다 ‘누구에게 얼마 동안 어떤 생활을 남길 것인지’를 먼저 정한다.

### ⑥ 은퇴·연금 통장

- 국민연금 예상액
- 퇴직연금·IRP
- 개인연금·연금보험
- 임대·사업·금융소득
- 은퇴 시점
- 은퇴생활비
- 연금 개시시점
- 물가와 장수위험

연금은 상품 수익률만 비교하지 않고 다음 순서로 설계한다.

1. 은퇴 후 필요한 월생활비
2. 공적·퇴직연금 예상 유입
3. 부족한 월현금흐름
4. 은퇴 전 적립 가능액
5. 개시시점 분산
6. 건강보험료·세금·유동성 확인
7. 배우자 사망 후 소득 감소 시나리오
8. 장기요양 비용과 별도 구분

제도별 금액·한도·세율은 코드에 영구 하드코딩하지 않는다. 공식자료 출처, 시행일, 검수일을 가진 버전형 데이터로 관리한다.

### ⑦ 간병·장기요양 통장

- 가족 중 주 돌봄자
- 돌봄 가능한 시간
- 치매·뇌혈관·파킨슨 등 장기요양 위험
- 간병인 사용
- 간호간병통합
- 장기요양등급
- 재가급여
- 시설급여
- 복지용구
- 가족 휴직·소득감소

재가급여 상담은 상품부터 설명하지 않는다.

1. 고객이 집에서 생활하기를 원하는지
2. 가족이 실제 돌봄 가능한 시간
3. 방문요양·방문간호·주야간보호·복지용구 등 필요한 서비스
4. 공적 장기요양보험으로 해결되는 부분
5. 본인부담과 비급여
6. 민영보험의 현금·서비스 보완
7. 시설 전환 시 비용
8. 배우자와 자녀 부담 변화

### ⑧ 자산이전·상속 통장

- 부동산·금융자산
- 부채
- 상속 예상 구조
- 유동성
- 종신보험 목적
- 증여 이력
- 가업·법인
- 세무·법률 전문가 협업

프로그램은 세무·법률 결론을 단정하지 않고, 예상 쟁점과 전문의뢰 체크리스트를 만든다.

## 3. 한 번의 상담 흐름

### 0단계: 동의와 목적

- 고객정보 활용 동의
- 오늘 상담에서 해결할 한 가지
- 가입이 아니라 진단과 선택이 목적임을 고지

### 1단계: 삶의 숫자

- 가족
- 직업
- 소득
- 지출
- 대출
- 자산
- 은퇴
- 건강
- 돌봄

필수값이 없으면 분석 결과에 `가정` 또는 `확인 필요` 표시.

### 2단계: 현재 구조

- 보험 PDF
- 연금계좌
- 퇴직연금
- 대출
- 자산
- 청구이력
- 납입면제
- 계약변경

### 3단계: 시간축 시뮬레이션

- 지금
- 질병 발생
- 3개월 소득중단
- 은퇴
- 배우자 사망
- 장기요양
- 상속

각 시점의 유입·유출과 부족액을 표시한다.

### 4단계: 강점 인정

현재 잘 준비된 항목을 먼저 보여준다.

### 5단계: 핵심 공백 1~3개

신입이 10개 문제를 쏟아내지 않게 한다. 고객 영향이 큰 순서로 최대 3개만 우선 설명한다.

### 6단계: 실제 지급·사후관리 사례

고객 상황과 관련 있는 검증 사례 1~2개만 제시한다.

- 동일 질병·수술과 관련 있는가
- 지급명세서로 검증되었는가
- 개인정보와 동의가 처리되었는가
- 동일 지급을 보장하지 않는다는 문구가 있는가

### 7단계: A/B/C 선택

- A: 기존 최대 유지 + 핵심만 보완
- B: 보험료 재배치 + 연금·저축 여력 확보
- C: 은퇴·간병·상속까지 통합

### 8단계: 결정과 후속조치

- 오늘 결정
- 확인할 약관
- 추가서류
- 담당자
- 일정
- 다음 상담
- 청구·사후관리 약속

## 4. 화면 모드

### 신입 모드

- 질문을 한 문장씩 제시
- 질문 이유 표시
- 고객 답변 예시
- 다음 질문 추천
- 하면 안 되는 표현
- 관리자 확인이 필요한 지점
- 숫자 설명용 쉬운 비유
- 상담 종료 후 자동 피드백

### 실전 보조 모드

- 왼쪽 고객답변
- 가운데 계산·분석
- 오른쪽 말할 문장
- 중요 질문 누락 경고
- 문서 근거 바로보기

### 전문가 모드

- 빠른 입력
- 규칙 수정
- 분석 가중치
- 제안 시나리오 편집

### 관리자 검수 모드

- 신입이 입력한 사실
- AI 해석
- 고객에게 보여줄 결과
- 수정 전/후
- 승인/반려
- 코칭 코멘트
