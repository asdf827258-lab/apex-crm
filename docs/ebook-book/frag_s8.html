제 8 부

처음 켤 때 — 대표가 한 번만 하는 일

설계사가 할 일이 아닙니다. 대표가 세 가지를 한 번 해 두면, 그다음부터 팀 전체가 아무것도 안 해도 됩니다. 다만 순서가 있습니다.

앱이 「안 된다」는 말의 대부분은 고장이 아닙니다. 이 세 가지 중 하나를 아직 안 한 것입니다. 고장과 설정을 구분할 줄 알면 물어볼 일이 절반으로 줄어듭니다.

1
서버 준비 — SQL 한 번 돌리기10분
홈 맨 위 배너에 준비 SQL 이 있습니다. 눌러서 복사 → Supabase 의 SQL Editor 에 붙여넣기 → RUN. 현재 판은 34입니다. 배너에 적힌 판 번호와 다르면 다시 돌리십시오.
홈 배너Supabase SQL Editor
2
메뉴 구성 저장하기SQL 뒤에
1번을 끝낸 뒤에, 메뉴 구성이 남아 있는 PC 에서 설정 → 도구 접근 → 저장을 누릅니다. 이 한 번으로 구성이 서버에 올라가 모든 기기에서 같아집니다.
설정도구 접근
3
서버 열쇠 두 개 넣기재배포까지
홈 배너의 「🔑 열쇠 넣기」가 다섯 걸음으로 안내합니다. 열쇠 두 개를 Netlify 환경변수에 넣고 반드시 재배포하십시오. 넣기만 하고 재배포를 안 하면 적용되지 않습니다.
홈 배너 🔑Netlify 환경변수재배포

순서를 바꾸지 마십시오 2번을 1번보다 먼저 하면 기본값이 서버를 덮습니다. 공들여 짜 둔 메뉴 구성이 조용히 사라지고, 없어진 줄도 모른 채 며칠이 갑니다.

1번을 안 하면 안 되는 것

SQL 을 안 돌려도 앱은 열립니다. 그래서 안 한 줄 모릅니다. 안 되는 것은 이 넷입니다.

  • 사업계획서 적용 — 세운 계획이 화면에 반영되지 않습니다.
  • 중복 아이디 삭제 — 같은 사람이 둘로 남아 숫자가 두 번 세어집니다.
  • 메뉴 구성 서버 저장 — 2번을 해도 저장되지 않습니다. 그래서 순서가 중요합니다.
  • 내 소개 동기화 — 집·사무실·태블릿에서 각각 다른 소개가 나갑니다.

3번을 안 하면 안 도는 것

열쇠 두 개는 사람이 자는 동안 도는 일을 위한 것입니다. 낮에 손으로 쓰는 화면은 열쇠가 없어도 대부분 열립니다. 그래서 없는 줄 모르고 몇 달을 씁니다.

언제무엇이 도는가
새벽 5시AI 부서 보고 — 팀 전체를 읽어 리더 화면에 올려 둡니다
새벽상담 준비 — 오늘 만날 고객 자료를 미리 정리해 둡니다
평일 장 마감 후종가 수집 — 주식·펀드 평가액이 그날 값으로 맞춰집니다
아침투자 브리핑 — 간밤 시장을 요약해 둡니다
매월성과 리포트 — 월간 실적이 자동으로 만들어집니다

비어 있으면 대개 열쇠입니다 AI 조직 라이브나 대표 브리핑이 텅 비어 있다면 고장이 아니라 열쇠가 없는 것입니다. 시스템 점검에서 먼저 확인하십시오.

열쇠를 다루는 규칙

열쇠 값은 이 책에 적지 않았습니다. 앞으로도 적지 않습니다. 카톡·메일·문서로 돌리지 마십시오. 넣는 자리는 Netlify 환경변수 한 곳이고, 어떤 열쇠를 어디서 받는지는 홈 배너의 「🔑 열쇠 넣기」가 화면에서 안내합니다. 화면 밖으로 나온 열쇠는 이미 새어 나간 열쇠입니다.

다 됐는지 확인하는 법

세 가지를 마쳤으면 아래 두 화면만 열어 보면 됩니다. 빨간 줄이 없으면 끝난 것입니다.

  • 출발 점검 — 처음 켤 때 필요한 것이 다 있는지 한 장으로 보여 줍니다.
  • 시스템 점검 — 서버와 연결 상태를 봅니다. 뭔가 안 될 때 여기부터 여십시오.
  • 홈 배너 — 다 됐으면 배너가 사라집니다. 배너가 남아 있으면 아직 남은 것이 있습니다.

이 장을 한 줄로

SQL 먼저, 그다음 메뉴, 마지막에 열쇠. 순서를 지키면 한 번으로 끝나고, 순서를 어기면 해 놓은 것이 덮입니다.
