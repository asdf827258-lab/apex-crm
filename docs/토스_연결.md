# 토스증권 연결하기 — 집이나 서버에서

## 왜 이렇게 하나

토스는 **호출하는 IP를 등록**해야 토큰을 줍니다. 그런데 Netlify 함수가 나갈 때 쓰는
IP는 배포할 때마다 바뀝니다. 직접 확인한 것만 세 번입니다.

```
3.144.168.102  →  18.222.65.41  →  3.16.137.242
```

등록해 놓아도 코드 한 줄만 고치면 끊깁니다. **서버리스에서는 풀 수 없는 문제입니다.**

그래서 토스에 닿는 부분만 떼어, IP가 변하지 않는 곳에서 돌립니다.

```
[집 PC · 작은 서버]                    [Netlify]
 toss-agent.js ──토스 API──> 시세·수급
       │
       └──> Supabase <────────────── market.js 가 읽기만
                                          │
                                          └──> 앱 화면
```

토스와 말을 섞는 건 `scripts/toss-agent.js` **하나뿐**입니다.

> **주문 기능은 없습니다.** 이 파일에 토스 규격의 `/orders` 계열을 부르는 곳이
> 한 군데도 없습니다. 읽기만 합니다.

---

## 1. 키 받기

토스증권 **PC 웹** → 설정 → Open API
(기업 신청 페이지가 아닙니다. 여기서 헤맸습니다.)

`client_id` 와 `client_secret` 을 받습니다.

## 2. 저장소를 받고 값을 넣기

```bash
git clone https://github.com/asdf827258-lab/apex-crm
cd apex-crm
git checkout claude/toss-api-crm-stock-fund-yq1hap
```

저장소 안에 `.env` 파일을 만듭니다.

```
TOSS_CLIENT_ID=여기에_client_id
TOSS_CLIENT_SECRET=여기에_client_secret
SUPABASE_SERVICE_ROLE_KEY=여기에_service_role_키
```

Supabase 키는 Supabase → Project Settings → API → `service_role` 입니다.

> `.env` 는 `.gitignore` 에 들어 있습니다. **깃에 올라가지 않는지 한 번 확인하세요** —
> `git status` 에 `.env` 가 보이면 안 됩니다.

## 3. IP 확인하고 등록

```bash
node scripts/toss-agent.js --check
```

이렇게 나옵니다.

```
토스증권 연결기 — 주문 기능 없음 (읽기 전용)

16:13:12 나가는 IP: 121.xxx.xxx.xxx  ← 이 값이 토스 허용 IP 에 등록돼 있어야 합니다

❌ IP 가 등록돼 있지 않습니다 (403). 아래 IP 를 토스증권 PC 웹 → 설정 →
   Open API 의 허용 IP 에 넣으세요.
   등록할 IP:  121.xxx.xxx.xxx
```

**그 IP를 토스에 등록**하고 다시 `--check` 를 돌립니다. 이렇게 나오면 끝난 겁니다.

```
16:15:40 ✅ 토큰 발급 성공 — 연결됐습니다
16:15:41 ✅ 시세 확인 — 삼성전자 274,500원 (14:32:11)

연결에 문제가 없습니다. 이제 --once 나 반복 실행으로 쓰세요.
```

## 4. 돌리기

```bash
node scripts/toss-agent.js --once   # 한 번만 받아서 저장
node scripts/toss-agent.js          # 장중에 60초마다 (Ctrl+C 로 종료)
```

간격은 `TOSS_INTERVAL_SEC` 로 바꿉니다. 받아올 종목은 기본적으로
**Supabase의 보유 종목**에서 가져옵니다. 따로 정하려면 `TOSS_CODES=005930,000660`.

### 계속 켜 두려면

**맥·리눅스** — `crontab -e` 에 넣습니다. 장중에만 돕니다.

```
*/1 9-15 * * 1-5  cd /경로/apex-crm && /usr/bin/node scripts/toss-agent.js --once >> /tmp/toss.log 2>&1
```

**윈도우** — 작업 스케줄러에서 `node scripts/toss-agent.js --once` 를 1분마다.

반복 실행 모드(`--once` 없이)를 그냥 켜 두어도 됩니다. 장 시간이 아니면 스스로 쉽니다.

---

## 5. 웹이 이 값을 쓰게 하기

Netlify → Site settings → Environment variables 에 이미 있는 것들 외에
`SUPABASE_SERVICE_ROLE_KEY` 가 들어 있으면 **자동으로 씁니다.** 따로 켤 것이 없습니다.

시세 순서는 이렇게 됩니다.

```
① 토스 직접        Netlify IP 가 등록돼 있으면 (보통 실패)
①' 토스 중계       ← 집에서 돌린 값. 15분 이내일 때만
② 한국투자증권      KIS 키가 있으면
③ 공공데이터포털    전일 종가
④ 공개 지연 시세    키가 하나도 없을 때
```

**⚠️ 15분이 넘으면 중계를 아예 건너뜁니다.** 집 인터넷은 IP가 바뀌고 PC는 꺼지므로
끊기는 건 예외가 아니라 일상입니다. 끊긴 줄 모르고 어제 값을 현재가 자리에 놓으면,
연결이 아예 없는 것보다 나쁩니다.

---

## 6. IP가 바뀌면

가정용 인터넷은 IP가 바뀔 수 있습니다. 반복 실행 모드로 돌리면 **스스로 알아채고
크게 알립니다.**

```
======================================================================
  ⚠️  나가는 IP 가 바뀌었습니다:  121.aaa.bbb.ccc  →  121.xxx.yyy.zzz
     토스증권 PC 웹 → 설정 → Open API 에서 허용 IP 를 새 값으로 바꾸세요.
     바꾸기 전까지는 토스 호출이 전부 403 으로 막힙니다.
======================================================================
```

바꾸는 동안에도 화면은 비지 않습니다 — 중계가 늙으면 공개 지연 시세로 내려갑니다.

고정 IP를 쓰고 싶으면 통신사에 고정 IP 상품을 신청하거나, 작은 클라우드 서버
(고정 IP가 기본으로 붙습니다)에 이 스크립트만 올리면 됩니다.

## 무엇을 받아오나

| 무엇 | 어디에 저장 |
|---|---|
| 현재가 | `invest_prices` (오늘 날짜 · `src='toss HH:MM'`) |
| 투자자별 매매동향 (상위 8종목) | `invest_briefs` (`kind='toss_flows'`) |
| 거래대금 랭킹 10 | 위와 같은 행 |

**마이그레이션이 필요 없습니다.** 이미 있는 표만 씁니다.

수급·랭킹은 10바퀴에 한 번만 받습니다. 자주 안 바뀌는데 매번 부르면 호출 한도를
시세가 아니라 거기에 씁니다.

---

## ⚠️ 커뮤니티는 API에 없습니다

토스 공식 규격(`openapi.json` v1.2.14) 엔드포인트 33개를 전부 확인했습니다.
**종목토론·댓글·의견·뉴스·리포트는 없습니다.** 규격 전문에 `community`,
`comment`, `opinion`, `sentiment`, `news`, `discussion` 단어 자체가 없습니다.

IP 문제를 풀어도 사람들의 이야기는 나오지 않습니다. 그건 토스 앱·웹 화면에만
있습니다. 앱의 종목 옆 **'토스' 버튼(딥링크)** 이 그 화면을 바로 열어 줍니다 —
키도 승인도 없이 지금도 됩니다.

대신 **수급**은 줍니다. 투자자별 매매동향·공매도·프로그램매매·신용거래·대차거래·
랭킹. 누가 무슨 말을 했는지가 아니라 **실제로 무엇을 샀는지의 기록**이라,
"남들 생각을 참고한다"가 목적이었다면 이쪽이 오히려 낫습니다.

## 잘 안 될 때

| 나오는 말 | 뜻 | 할 일 |
|---|---|---|
| `IP 가 등록돼 있지 않습니다 (403)` | 그대로입니다 | 화면에 찍힌 IP를 토스에 등록 |
| `키가 틀렸습니다 (401)` | id/secret 오류 | `.env` 확인. **앞뒤 공백**이 흔한 원인 |
| `이 키에 권한이 없습니다` | scope 문제 | 토스 신청 범위에 시세가 있는지 확인 |
| `호출이 너무 잦습니다 (429)` | 한도 초과 | `TOSS_INTERVAL_SEC` 를 늘리기 |
| `필요한 값이 없습니다` | `.env` 미인식 | 저장소 루트에서 실행하고 있는지 확인 |

검사를 돌려 계산이 멀쩡한지 볼 수 있습니다. 네트워크를 타지 않습니다.

```bash
node scripts/check-toss-relay.js    # 중계 신선도 판정 17개
node scripts/check-public-quote.js  # 공개 지연 시세 18개
```
