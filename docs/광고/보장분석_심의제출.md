# 보장분석 신청 홈페이지 — 심의 제출 준비

심의에 올릴 대상물과, 올리기 전에 채워야 할 자리, 그리고 페이지에 쓴 표현마다
무슨 근거로 썼는지를 한곳에 모아 둔 문서입니다. 심의 담당자가 묻는 것은
대부분 "이 문장의 근거가 무엇이냐" 하나입니다.

## 대상물

| 항목 | 내용 |
|---|---|
| 파일 | `보장분석/index.html` |
| 주소 | `/보장분석` (별칭 `/bojang`) |
| 성격 | 보장분석 상담 신청을 받는 공개 랜딩페이지 |
| 매체 | 메타(페이스북·인스타그램) 유료광고 도착지, 카카오톡 공유 |
| 수집 | 이름·연락처·상담 요청 내용 |

## 올리기 전에 채울 자리

페이지에서 대괄호 `[ ]` 로 표시된 곳이 전부입니다. 화면에서 붉게 보입니다.

- [ ] 설계사 이름
- [ ] 소속 대리점(보험사) 이름과 등록번호
- [ ] 생명보험협회·손해보험협회 등록번호
- [ ] 사업자등록번호 · 사업장 주소 · 연락처
- [ ] 광고심의필 번호와 유효기간 (심의 통과 후 받는 번호)
- [ ] 개인정보 보유기간 일수 (동의 문구 안)
- [ ] 개인정보처리방침 주소 — `SITE.privacyUrl`
- [ ] 상담 사례 두 건의 실제 내용과 산정 근거
- [ ] 카카오톡 오픈채팅 주소 — `SITE.kakaoUrl` (비워 두면 카톡 버튼이 안 보입니다)

사례 두 건은 지금 자리만 잡아 두었습니다. **실제 상담 건으로 채우되,
수치를 쓰면 그 수치가 어떻게 나온 것인지 함께 적어야 합니다.**
근거를 댈 수 없는 수치는 넣지 않는 편이 심의도 빠르고 뒤탈도 없습니다.

## 표현별 근거

| 페이지에 쓴 표현 | 근거 · 성격 |
|---|---|
| "여섯 가지 중 하나라도 해당되면 지금이 점검할 때입니다" | 상담을 권하는 안내이며 가입 권유가 아님. 바로 아래에 "점검은 가입 권유가 아니며, 실제 보장 여부와 지급 금액은 특약 구성과 약관상 지급 사유에 따라 달라진다"를 병기 |
| 점검 6문항 (지인 권유·보험료 부담·오래된 계약·실손 세대 전환·진단금 범위·여러 곳에 흩어짐) | 상담을 권하는 상황 예시. 특정 상품이나 보장금액에 대한 주장이 아니며, 고객이 스스로 해당 여부를 고르는 형식 |
| 점검 결과 "N가지가 해당됩니다" | 고객이 직접 고른 항목 수를 되돌려 주는 것. 보장 유무나 가입 필요성에 대한 판정이 아니며, 증권을 확인해야 안다는 점을 함께 표시 |
| "먼저 전화하지 않습니다" | 운영 방침. 지킬 수 있는 약속만 적었음 |
| "주민등록번호와 계정 비밀번호는 받지 않습니다" | 폼에 해당 입력칸이 실제로 없음 |
| "상담은 무료입니다" | 보장분석·상담에 비용을 받지 않음. 보험료·진료비·서류 발급비는 고객 부담임을 FAQ와 푸터에 명시 |
| "해지보다 유지 먼저" | 감액·감액완납·연장정기·약관대출·납입일시중지 등 계약 유지 대안을 먼저 검토한다는 상담 방침 |

## 일부러 넣지 않은 것

경쟁 페이지에서 흔히 보이지만, 근거를 대기 어려워 뺐습니다.

- 수상 배지("고객만족지수 1위" 등)
- 평균 보험료 절감률, 상담 만족도 같은 통계 수치
- "최대 N배", "무조건", "확정" 같은 단정 표현
- 사은품·경품 (넣게 되면 "보험계약 체결과 무관, 상담 완료 기준, 1인 1회"를 문구에 넣어야 합니다)

## 개인정보

| 구분 | 내용 |
|---|---|
| 수집 항목 | 이름, 연락처, 상담 요청 내용(고른 점검 항목·궁금한 점) |
| 수집 목적 | 보장분석 상담 및 결과 안내 |
| 보유 기간 | 상담 종료 후 [ ]일 이내 파기 |
| 필수 동의 | 개인정보 수집·이용 — 동의 없이는 접수되지 않음(화면·서버 양쪽에서 막음) |
| 선택 동의 | 보험사 전산 가입내역 확인 — 본인인증 후, 담당자 권한 범위에서 |
| 저장 위치 | Supabase `web_leads` 표. 읽기는 대표·본부장만 가능 |
| 위탁 | 신청 접수·알림 발송 업무. 푸터에 위탁 사실을 적어 두었고, 실제 쓰는 서비스명을 채워야 합니다 |

지우는 기능은 만들지 않았습니다. 잘못 들어온 신청은 상태를 `스팸` 으로 바꿔 남깁니다.
보유기간이 지난 자료의 파기는 별도 절차로 처리합니다.

## 광고 소재

랜딩페이지와 **광고 소재(카피·이미지)는 심의 대상이 다를 수 있습니다.**
메타에 올릴 카피 5종은 `docs/광고/보장분석_랜딩_해부.html` 에 있습니다.
소속사 지침에 따라 소재도 함께 올려야 하는지 먼저 확인하세요.

## 심의 후

번호가 나오면 두 곳을 고칩니다.

1. `보장분석/index.html` 푸터의 `광고심의필 제[ ]호 · 유효기간 [ ] ~ [ ]`
2. 유효기간 종료일을 달력에 넣어 둡니다 — 기간이 지난 광고를 그대로 두면 그것도 문제입니다

문구를 고친 뒤 `node scripts/check-lp.js` 를 돌리면 준법 문구가 화면에 남아 있는지
자동으로 확인합니다.
