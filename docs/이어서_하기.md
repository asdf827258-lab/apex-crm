**토스증권 Open API** — 토큰 발급까지 성공했습니다. 마지막 벽은 토스가 요구하는
**IP 허용목록**인데, Netlify 함수의 나가는 IP 가 배포할 때마다 바뀝니다
(`3.144.168.102` → `18.222.65.41` 로 바뀌는 것을 확인했습니다).
`config/market.json` 에 `base` 와 `token_path` 는 채워져 있고 `paths.quote` 는
비워 두었습니다. 그래서 `tossReady()` 가 false 라 다른 시세원으로 그냥 넘어갑니다.
고정 IP를 쓸 수 있는 곳에 함수를 올리기 전에는 진전이 없습니다.

## 2. 백테스트 결과 — 여기가 지금 가장 중요한 지점

키 없이 받는 공개 시세로 24개월을 돌렸습니다 (`--public`).

```
자산        전략                거래    승률        손익     낙폭%     샤프
SPY       mean_reversion      165   39.4%     -5,726     6.03   -2.66
QQQ       mean_reversion      123   37.4%       -422     4.54   -0.12
BTC/USD   breakout            626   32.8%    -41,311    43.59   -1.33
GLD       trend_following       2   50.0%       -401     0.45  -12.78
USO       trend_following      13   46.1%      1,157     2.69    1.51
합계                            929   34.8%    -46,704    46.73   -1.20
                                       최종 잔고 53,296 · -46.70%

관문 6개 중 4개 실패
  ✅ 거래가 실제로 발생했는가       929건
  ❌ 최대 낙폭 15% 이하         46.73%
  ❌ 샤프 지수 양수             -1.20
  ✅ 비용이 0 이 아닌가          5.0bps
  ❌ 한 자산에 쏠리지 않았는가      BTC/USD 하나가 손실의 88%
  ❌ 자산별 기간이 비슷한가        SPY 86일 vs GLD 1061일
```

### 원인은 전략이 아니라 비용입니다

같은 데이터에 비용만 0으로 두면 이렇게 바뀝니다.

| | 5bps (실제) | 0bps |
|---|---|---|
| SPY | -5,726 | +8,324 (샤프 2.17) |
| QQQ | -422 | +14,346 (샤프 2.71) |
| BTC/USD | -41,311 | -1,856 (샤프 0.03) |
| 합계 | **-46.7%** | **+22.6%** |

`results/trades.csv` 의 약정금액을 더해 봤습니다. 24개월 동안 **8,400만 달러**를
굴렸습니다. 계좌는 10만 달러입니다. 왕복 10bps면 그것만 8만 4천 달러 — 계좌의 84%.

1% 룰이 손절폭으로 수량을 정하는데, 15분봉 평균회귀는 손절폭이 좁아서 매번
계좌의 92%짜리 포지션이 나옵니다. **위험은 1%인데 비용은 92%에 붙습니다.**
신호에 우위는 있는데(SPY·QQQ 샤프 2.2/2.7) 그 우위보다 통행료가 큽니다.

포지션 크기를 줄이는 것으로는 안 됩니다 — 손익과 비용이 같은 비율로 줄어
결과가 그대로입니다. **거래 횟수를 줄이거나 건당 기대 이동폭을 키워야 합니다.**

BTC/USD 는 다릅니다. 비용을 0으로 해도 샤프 0.03에 낙폭 26%입니다.
**우위 자체가 없습니다.**

### '24개월' 이 사실이 아니었던 것

공개 시세는 봉 종류마다 주는 기간이 다릅니다.

```
SPY·QQQ  15분봉    86일   ← 15분봉은 60일까지만 준다
BTC/USD  1시간봉  729일
GLD·USO  4시간봉 1061일
```

다섯을 한 잔고 곡선에 태워 놓고 합계를 뽑았으니, SPY 는 석 달 BTC 는 2년을 잰
숫자를 더한 셈입니다. 여섯 번째 관문으로 넣었습니다. **전략을 비교할 생각이면
이 관문부터 초록불이어야 합니다.**

### 다음 갈림길 — 결정이 필요한 곳

1. **BTC/USD 를 뺀다** — 비용 없이도 우위가 없습니다. 빼면 -46.7% → -7.7%.
2. **SPY·QQQ 의 진입 문턱을 올린다** — 기대 이동폭이 왕복 비용의 몇 배 이상일 때만
   진입. 봉을 1시간으로 늘려 봤는데 거래가 오히려 늘어 더 나빴습니다(-41%).
   시간축이 아니라 문턱 문제입니다.
3. **GLD·USO 는 판단 보류** — 2건과 13건으로는 아무 말도 할 수 없습니다.

2번은 파라미터를 만지는 일이라 과최적화 위험이 있습니다. 손대려면 기간을 나눠
(앞으로 맞추고 뒤로 검증) 돌리는 틀부터 만들어야 합니다. 지금은 없습니다.

> 관망 플랜 ①번에 "하나라도 ✗면 여기서 멈춘다"고 적어 두었으므로,
> **모의 시뮬레이션은 아직 시작하지 않았습니다.**

한글 폰트가 없는 환경에서는 그래프 제목에 한글을 빼고 그립니다. 표와 숫자는

## 5. 뉴스·전망은 토스 없이 이미 됩니다

토스 API 가 막혔다고 뉴스까지 막힌 게 아닙니다. 뉴스는 처음부터 별개였습니다.

`config/sources.json` 의 RSS 를 직접 받습니다 — 연합뉴스(경제·증권) · 한국경제 ·
매일경제 · 이데일리 · SBS Biz · 보험신문 · 한국보험신문. 토스가 앱에 싣는 기사도
같은 통신사에서 온 것입니다. **중간상을 거치지 않고 원본에서 바로 받는 쪽이
오히려 낫습니다.**

흐르는 길:

```
config/sources.json (RSS)
   ↓  평일 16:10
market-daily  →  invest_briefs (kind='market_daily')  AI 시황 요약
              →  invest_briefs (kind='news_daily')    헤드라인 원문 + 링크
   ↓  다음날 07:00
invest-daily  →  계좌별 아침 브리핑에 "## 시장·뉴스" 항목으로 실린다
```

요약본과 헤드라인 원문을 **둘 다** 남깁니다. 요약만 있으면 무슨 기사를 보고 쓴
글인지 확인할 수 없고, 확인할 수 없는 요약은 투자 판단에 쓸 물건이 아닙니다.

브리핑을 쓰는 AI 에 건 제약:

- 제목만 준다. **기사 본문을 읽은 것처럼 내용을 지어내면 안 된다.**
  제목에 없는 수치·인용·인과관계 금지.
- 뉴스와 계좌를 억지로 잇지 않는다. 닿는 헤드라인이 없으면
  "직접 닿는 것은 없다" 고 쓰고 끝낸다. 그게 맞는 답이다.
- 앞날을 단정하지 않는다. "오르겠다/빠지겠다" 대신 **무엇을 확인하면 판단이
  갈리는지** 를 쓴다.
- 며칠 지난 시황이면 며칠 지났다고 적는다.

**제목과 링크만 저장하고 기사 본문은 저장하지 않습니다.** 남의 저작물이라,
읽을 사람은 링크를 눌러 원문으로 갑니다. 사내에서 돌려 보는 것과 밖으로 다시
내보내는 것은 다른 문제이므로, 고객에게 그대로 전달할 생각이면 각 언론사의
이용 조건을 먼저 확인해야 합니다.

## 6. 넘어졌던 자리 — 같은 데서 또 넘어지지 않으려고 적어 둡니다

- **일정이 걸린 Netlify 함수는 주소로 못 엽니다** (403). 손으로 돌리려면
  Netlify 대시보드 → Functions → 해당 함수 → Run.
- **`_redirects` 는 실제 파일이 있으면 건너뜁니다.** 404로 막으려면 `404!` 처럼
  느낌표를 붙여야 합니다. 배포 뒤 `curl` 로 확인하기 전에는 알 수 없었습니다.
- **`invest_txns.kind` 에 `'cash'` 는 들어가지 않습니다.**
  buy·sell·deposit·withdraw·dividend·fee 뿐입니다(제약조건).
  현금은 원장을 더하고 빼서 구합니다.
- **`to_regproc('f(uuid,uuid)')` 는 인자 목록을 못 읽어 항상 null 입니다.**
  함수 존재 확인은 `pg_proc` 를 세는 쪽으로 하세요.
- **신호를 `account_id` 로만 거르면 0건이 됩니다.** 전략은 보통 계좌를 모른 채
  신호를 냅니다. `or=(account_id.eq.X,account_id.is.null)` 로 둘 다 받습니다.
- **아침 07시 함수에서 `today` 로 어제 자료를 찾으면 영원히 0건입니다.**
  자료의 기준일(`nav_date` / `price_date`)로 찾으세요.
- **환율을 모를 때 임의의 값을 쓰면 안 됩니다.** USD 종목을 빼고, 뺐다고
  리포트에 적습니다. 안 그러면 "해외주식 0%" 같은 조용히 틀린 숫자가 나옵니다.
