## 할 일 — 세 걸음

### ① 키 발급

<https://console.anthropic.com> → 로그인 → **API Keys** → **Create Key**

`sk-ant-` 로 시작하는 문자열이 나옵니다. **이 화면을 떠나면 다시 못 봅니다.**
바로 복사해 두세요.

> 결제 수단 등록이 필요합니다. 이 용도로는 한 달에 몇 천 원 수준입니다
> (아래 '얼마나 드나' 참고).

### ② Netlify 에 넣기

<https://app.netlify.com> → **apex-os-yunpro** → Site configuration →
**Environment variables** → **Add a variable**

```
Key    ANTHROPIC_API_KEY
Value  sk-ant-...   (①에서 복사한 것)
Scopes 전부 (기본값 그대로)
```

**Save** 를 누릅니다.

### ③ 다시 배포

환경변수는 **다음 배포부터** 적용됩니다. 저장만 하면 안 바뀝니다.

**Deploys** 탭 → **Trigger deploy** → **Deploy site**

2~3분 뒤 <https://apex-os-yunpro.netlify.app/analyst/> 를 열고
'삼성전자' 를 눌러 보세요. 호재·악재 배지가 붙어 있으면 된 겁니다.

```

```

`"분석":"AI 준비됨"` 이면 성공입니다.
`"ANTHROPIC_API_KEY / GEMINI_API_KEY 없음"` 이면 ③을 안 한 것입니다.

## 얼마나 드나

한 종목을 분석할 때 기사 30건 정도를 제목만 보냅니다.

| | |
|---|---|
| 한 종목 1회 | 약 3~7원 |
| 하루 10종목 × 3회 | 약 100~200원 |
| 한 달 | **약 3,000~6,000원** |

기사 본문을 안 보내기 때문에 쌉니다. 본문까지 보내면 열 배 이상 됩니다.

**한도를 걸어 두세요.** console.anthropic.com → Settings → Limits 에서
월 상한(예: 10 USD)을 정하면 그 이상 안 나갑니다. 처음에는 걸어 두는 편이 낫습니다.

## 돈을 아끼는 쪽이면 — Gemini

`GEMINI_API_KEY` 도 같은 자리에 쓸 수 있습니다. 무료 한도가 넉넉합니다.

<https://aistudio.google.com/apikey> → Create API key

Netlify 에 `GEMINI_API_KEY` 로 넣으면 됩니다.
**둘 다 넣으면 Anthropic 을 먼저 쓰고, 실패하면 Gemini 로 넘어갑니다.**

한국어 금융 뉴스 판단은 Anthropic 쪽이 낫습니다. 다만 Gemini 로 먼저 써 보고
결과가 마음에 들면 그대로 두어도 됩니다 — 화면은 똑같이 채워집니다.

## 같이 넣으면 좋은 것 (선택)

### DART — 국내 공시

지금 국내 공시 칸에 `DART_API_KEY 가 없습니다` 라고 떠 있습니다.
**무료이고 자동 승인**입니다.

<https://opendart.fss.or.kr> → 인증키 신청 → 메일로 받은 키를
Netlify 에 `DART_API_KEY` 로 넣습니다.

미국 공시(SEC)는 키가 필요 없어서 **이미 나오고 있습니다.**

## 넣어도 안 되면

| 화면에 뜨는 말 | 뜻 | 할 일 |
|---|---|---|
| `AI 키 없음` | ③을 안 했다 | Trigger deploy |
| `Anthropic 401` | 키가 틀렸다 | 앞뒤 공백 확인. `sk-ant-` 로 시작하는지 |
| `Anthropic 429` | 한도 초과 | console 에서 남은 한도 확인 |
| `Anthropic 400` | 요청이 거절됨 | 그 문구 그대로 알려 주세요 |
| 배지가 일부만 붙음 | 형식 어긋난 기사를 버린 것 | 정상입니다. 아래 설명 참고 |

**마지막 줄이 정상인 이유** — AI 가 'positive' 라고 해 놓고 점수를 -0.9 로 주는
일이 있습니다. 둘 중 무엇이 참인지 알 수 없으므로 그 기사는 버립니다. 한쪽에
맞춰 다른 쪽을 고치면 있지도 않은 판단을 만들어 내는 것이라서요. 몇 건을 왜
버렸는지는 화면에 적힙니다.

## 알고 쓰셔야 하는 것

**AI 는 기사 제목만 봅니다.** 본문은 읽지 않습니다. 남의 저작물이기도 하고,
매체마다 구조가 달라 긁어오면 엉뚱한 글이 섞이기 때문입니다.

그래서 프롬프트에 이렇게 못 박아 두었습니다.

- 제목에 없는 수치·인용·인과관계를 쓰지 말 것
- 본문을 읽은 것처럼 쓰지 말 것
- 제목만으로 판단이 안 되면 중립으로 두고 중요도를 낮게 매길 것

**확신도(AI Confidence)는 근거가 없을수록 낮아집니다.** 기사가 적거나, 오래됐거나,
긍정·부정이 팽팽하거나, 시세를 못 받으면 내려갑니다. 기사가 아예 없으면 0 입니다.
낮게 나오면 그 숫자를 믿으세요 — 모르면서 확신하는 쪽이 제일 위험합니다.

**투자 판단의 근거로 삼기 전에 원문을 확인하세요.** 제목만 보고 내린 판단입니다.
투자성 상품은 원금손실이 발생할 수 있습니다.
