# NEW ADVISOR 90-DAY ACADEMY

## 교육 목표

90일 후 신입이 혼자 상품설명을 잘하는 것이 아니라, 프로그램의 가이드에 따라 **기본 재무진단 → 보장분석 → 연금·은퇴 → 간병·재가급여 → 후속관리**를 안전하게 진행한다.

---

## 1개월차 — 사실을 정확히 듣고 기록한다

### 1주차: 상담 태도와 준법

- 고객 동의
- 개인정보
- 적합성·적정성
- 단정·과장 금지
- 약관 우선
- 사실/해석/제안 구분
- 상담 기록

실습:
- 10분 라포
- 금지표현 고치기
- 고객정보 마스킹

통과 기준:
- 준법 퀴즈 90점
- 개인정보 오류 0건

### 2주차: 가계 현금흐름

- 소득
- 지출
- 대출
- 비상자금
- 저축여력
- 부양가족

실습:
- 5개 가상가정 입력
- 3개월 소득중단 시뮬레이션
- 한 줄 결론 만들기

### 3주차: 보험 기초와 실손

- 보험의 역할
- 실손과 정액
- 급여·비급여
- 진단·수술·치료
- 면책·감액·갱신
- 보험금 청구 흐름

실습:
- 지급사례 10건 분류
- 입금알림과 지급명세서 차이
- 필요한 서류 질문

### 4주차: 보장분석 기본

- 기존계약 강점
- 공백
- 중복
- 구조위험
- 유지·보완·확인

실습:
- PDF 3개 검수
- 고객용 1장 작성
- 관리자 피드백 반영

1개월 게이트:
- 기본상담 롤플레이 70점
- 사실오류 0건
- AI가 만든 숫자 검증률 100%

## 2개월차 — 위험과 은퇴를 연결한다

### 5주차: 암·뇌·심장과 소득공백

- 치료시간표
- 진단비의 생활비 역할
- 반복 치료
- 후유장해
- 자영업자 고정비

실습:
- 직장인/자영업자 비교
- 고객 질문 15개
- 사례 설명 3개

### 6주차: 수술·간병·청구 사후관리

- 수술특약 중첩
- 입원·통원
- 간병인
- 청구 후보 찾기
- 부지급 대응의 기본

실습:
- 업로드된 실제 지급사례 기반 케이스랩
- 청구서류 체크리스트
- 고객 카톡 안내

### 7주차: 연금과 은퇴 현금흐름

- 국민연금
- 퇴직연금·IRP
- 개인연금
- 은퇴생활비
- 연금 개시 분산
- 배우자 소득 감소
- 장수·물가 위험

실습:
- 40대 직장인
- 50대 자영업자
- 60대 은퇴직전
- 월 부족액 계산과 A/B/C안

### 8주차: 사망·상속·자산이전

- 가족생활비
- 대출
- 정기·종신 목적
- 상속 유동성
- 전문가 협업

실습:
- 사망보장 목적 한 문장
- 과도한 사망보험 조정
- 세무사 의뢰 질문지

2개월 게이트:
- 통합상담 롤플레이 80점
- 연금 부족액 계산 오류 0건
- 기존계약 무근거 해지권유 0건

## 3개월차 — 장기요양까지 전체 상담을 완성한다

### 9주차: 장기요양과 재가급여

- 공적 장기요양
- 등급과 서비스
- 방문요양·방문간호
- 주야간보호
- 복지용구
- 시설급여
- 가족 돌봄시간
- 민영보험 보완

실습:
- 70대 부부
- 치매 초기
- 뇌졸중 후 재활
- 자녀가 타지역 거주하는 가정

### 10주차: 제안 전후 비교

- 현재/제안
- 보험료
- 총 납입
- 갱신 비중
- 연금 적립 여력
- 장기요양 준비
- 새로 생기는 단점

실습:
- A/B/C안 발표
- 고객 반론 처리
- 관리자의 반대 역할

### 11주차: 실제 상담 동행

- 3건 참관
- 3건 일부 진행
- 2건 전체 진행
- 모든 상담 관리자 사전승인

AI 코칭:
- 말한 비율
- 질문 개수
- 고객 답변 반영
- 단정 표현
- 다음 행동 합의

### 12주차: 인증

필기:
- 준법
- 보험·연금·장기요양
- 청구·사후관리

실기:
- 45분 통합상담
- PDF 전후분석
- 고객용 1장
- 카톡 요약
- 관리자 질의응답

최종 인증 기준:

- 종합 85점 이상
- 준법 90점 이상
- 사실오류 0건
- 근거 없는 보험금·수익 단정 0건
- 고객 핵심목표를 결론에 반영
- 관리자 승인
