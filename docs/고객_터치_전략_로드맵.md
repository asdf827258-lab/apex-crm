# 고객 터치 전략 로드맵 — 누구에게 · 어떻게 · 무엇을 · 언제

작성 2026-08-19 · 앱의 「오늘의 터치」가 이 문서대로 움직입니다

---

## 0. 왜 만들었나

「30일 지났습니다」까지는 앱이 이미 말해 주고 있었습니다.
그런데 그 말만으로는 손이 안 나갑니다. 그 말을 듣고 나서도

- 전화를 걸까, 카톡을 보낼까
- 무슨 말로 열까
- 지금 이 사람이 먼저인가, 저 사람이 먼저인가

를 **또 생각해야** 하기 때문입니다. 생각할 게 남아 있으면 사람은 미룹니다.
그래서 세 가지를 한 줄에 붙였습니다 — **누구에게 · 어떻게 · 무엇을.**

---

## 1. 판정 규칙 — 위에서부터 먼저 맞는 하나

앱 화면의 「왜 이 순서인가」를 누르면 이 표가 그대로 나옵니다.
숨기지 않는 이유: **팀원이 납득해야 따라 합니다.**

| # | 방식 | 언제 걸리나 | 왜 그 방식인가 |
|---|---|---|---|
| 1 | ☎️ 전화 | 등록하고 **한 번도** 연락한 적 없음 (7일 경과) | 첫 연락은 글로 열리지 않습니다. 목소리가 먼저입니다 |
| 2 | ☎️ 전화 | **VIP**(월 100만원↑)인데 주기(14일)를 넘김 | 월 납입이 큰 고객입니다. 이 분들은 전화로 챙깁니다 |
| 3 | ☎️ 전화 | **60일** 넘게 소식 없음 | 오래 끊긴 관계는 글로 안 살아납니다. 전화 한 통이 훨씬 빠릅니다 |
| 4 | ☎️ 전화 | 최근 90일 접촉이 **전부 카톡·문자** (3건 이상) | 목소리를 한 번 넣어야 관계가 두터워집니다 |
| 5 | 💬 카톡 | 주기 넘김 + **암·사망 진단금이 안 잡힘** | 먼저 소식으로 문을 두드리고, 답이 오면 전화로 넘어갑니다 |
| 6 | ☎️ 전화 | 주기(30일) 넘김 | 30일 안에 한 바퀴 도는 것이 이 팀의 약속입니다 |
| 7 | ☎️ 전화 | 곧 때가 됨 + **팩트파인딩이 절반 미만** | 통화하면서 두세 칸만 채우면 됩니다 |
| 8 | 💬 카톡 | 곧 때가 됨 | 아직 여유가 있습니다. 가벼운 소식 한 건이면 충분합니다 |

**VIP 는 같은 규칙 안에서만 조금 앞으로 옵니다.** 규칙 사이를 건너뛰지 않습니다 —
「한 번도 연락한 적 없는 사람」보다 앞설 수는 없습니다. 그게 제일 급하기 때문입니다.

## 2. 로드맵 — 한 사람을 1년 동안 어떻게 도는가

### 0일차 — 등록한 날
```
할 것   전화 (첫 통화)
목적    "누구인지" 가 아니라 "무엇이 걱정인지" 를 듣는다
남길 것 팩트파인딩 최소 4칸 — 나이 · 직업 · 월 보험료 · 지금 있는 보장
왜      월 보험료가 없으면 앱이 VIP 인지 아닌지 판정을 못 합니다.
        VIP 를 놓치는 것이 이 시스템에서 가장 아픈 실수입니다.
```

### 7일차 — 아직 통화를 못 했다면
```
앱      「한 번도 연락한 적이 없습니다」 로 맨 위에 올립니다
할 것   전화. 카톡으로 대신하지 않습니다
```

### 1~30일 — 첫 달
```
1주차  전화 — 첫 통화 (위)
2주차  카톡 — 그 사람에게 맞는 소식 한 건 (앱이 골라 줍니다)
4주차  전화 — 보장 이야기의 문을 연다. 팩트파인딩 두세 칸을 더 채운다
```

### 30일마다 — 일반 고객
```
25일째  앱이 「곧 때가 됩니다」 (노랑) — 카톡 한 통이면 충분
30일째  앱이 「지금 연락해야 함」 (주황) — 전화
```

### 14일마다 — VIP (월 100만원 이상)
```
12일째  「곧 때가 됩니다」
14일째  「지금 연락해야 함」 — 전화. VIP 는 글로 때우지 않습니다
```

### 60일 넘어가면 — 되살리기
```
앱      「두 달 넘게 소식이 없습니다」 로 위로 올립니다
할 것   전화. 사과로 시작하지 않습니다 — 용건으로 시작합니다
        (사과로 시작하면 그 통화의 주도권이 넘어갑니다)
```

### 분기마다 — 보장 점검
```
할 것   비포&애프터 한 장 (앱이 만들어 줍니다)
왜      "달라진 게 없는지" 를 확인받는 자리가 있어야 재설계가 자연스럽습니다
```

## 3. 방식은 어떻게 갈리는가 — 전화 vs 카톡·문자

### ☎️ 전화로 가야 하는 자리
- **처음** — 첫 연락
- **오래** — 60일 넘게 끊김
- **큰 것** — VIP · 계약 변경 · 보장 공백
- **물어볼 게 있을 때** — 팩트파인딩이 비었을 때
- **글로만 이어져 왔을 때** — 최근 석 달이 전부 카톡이면

### 💬 카톡·문자로 충분한 자리
- **아직 여유가 있을 때** — 주기 안쪽
- **소식만 전할 때** — 세금·부동산·지원금·보험
- **문을 두드릴 때** — 보장이 비어 있는데 바로 전화하기 이른 사이

### 앱이 짚어 주는 알람
```
최근 30일 접촉 중 전화가 30% 아래면 →
"글로만 이어지면 숫자는 도는데 관계는 얇아집니다 — 오늘 세 통만 걸어 보세요"
```
- 접촉 기록이 **5건 미만이면 말하지 않습니다.** 표본이 적을 때 단정하면 잔소리가 됩니다.

## 4. 무엇을 전할까 — 소식 고르는 규칙

앱이 「고객에게 전할 뉴스」에 모아 둔 것 중에서, 그 고객에게 맞는 칸을 골라 줍니다.

| 고객이 이러면 | 이 칸에서 고릅니다 |
|---|---|
| VIP 이거나 **집이 있으면** | 세금 |
| **대출이 있으면** | 부동산 |
| **교육비가 나가면** | 지원금 |
| **암·사망 진단금이 비었으면** | 보험 |
| 그 밖에 | 경제 |

### 보낼 글에 지키는 것
- **고객 이름을 넣지 않습니다.** 「고객님」으로만 씁니다.
  잘못 보내도 누구인지 드러나지 않게 하기 위해서입니다.
- **누가 보내는지는 적습니다.** (설계사 이름)
- 소식은 **출처와 함께** 붙습니다.

## 5. 화면에서 어떻게 쓰는가

고객 365일을 열면 맨 위에 **「📋 오늘의 터치」** 가 섭니다.

```
[1] 홍○동  👑VIP  한 번도 없음 · 등록 40일
    ☎️ 전화 — 한 번도 연락한 적이 없습니다
    첫 연락은 글로 열리지 않습니다. 목소리가 먼저입니다.
    [☎️ 지금 걸기] [💬 보낼 글 복사] [✓ 했음]
```

- **☎️ 지금 걸기** — 폰에서 바로 전화가 걸리고, 동시에 「전화」 기록이 남습니다
- **💬 문자로 보내기** — 문자 앱이 열리면서 보낼 글이 이미 들어가 있습니다
- **📋 카톡 글 복사** — 복사해서 카톡에 붙여 넣으면 됩니다
- **✓ 했음** — 기록만 남깁니다 (다른 길로 연락했을 때)
- **📱 번호 넣기** — 번호가 아직 없을 때. **이 기기에만 저장되고 서버로 가지 않습니다**

기본 6명씩 보이고 「더 보기」로 늘립니다. 한 번에 30명을 보여 주면 아무도 안 합니다.

## 6. 앞으로 더 붙일 것 (아이디어)

지금 넣지 않은 것들입니다. 필요하시면 말씀해 주십시오.

| 아이디어 | 무엇 | 왜 지금 안 넣었나 |
|---|---|---|
| 생일 터치 | 생일 D-3 에 맨 위로 | 생일이 채워진 고객이 아직 적습니다 |
| 계약일 터치 | 가입 1주년마다 점검 제안 | 계약일을 저장하는 칸이 아직 없습니다 |
| 시간대 추천 | 그 고객이 잘 받는 시간대 | 통화 기록에 시각이 없습니다 |
| 자동 발송 | 정해진 날 자동으로 문자 | **사람이 보내야 합니다.** 자동 발송은 관계를 만들지 않습니다 |
| 팀 순위 | 이번 주 전화 많이 한 사람 | 숫자 경쟁이 되면 질이 떨어집니다 |
| 답장 추적 | 보낸 글에 답이 왔는지 | 카톡을 앱이 읽을 수 없습니다 |

## 7. 한 장 요약

```
누구에게  한 번도 없음 → VIP 넘김 → 60일 → 카톡만 → 보장 빔 → 30일 → 아는 게 적음 → 곧
어떻게    처음·오래·큰 것·물어볼 것 → 전화 /  여유·소식·문 두드리기 → 카톡
무엇을    VIP·집=세금 · 대출=부동산 · 교육비=지원금 · 보장 빔=보험 · 나머지=경제
언제      일반 30일 · VIP 14일 · 60일 넘으면 되살리기 · 분기마다 보장 점검
알람      최근 30일 전화 비율 30% 아래면 짚어 줍니다
```
